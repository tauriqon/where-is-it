# 📦 WhereIsIt 물건 등록 화면 상단 헤더 배너 제거 및 뷰포트 극대화 (v00183)

본 문서는 WhereIsIt 토스 인앱 미니앱의 물건 등록(AddTab) 화면에서 이미 하단 탭 바에서 `[+ 등록]`을 인지하고 진입한 사용자에게 중복 전달되던 **최상단 타이틀('새 물건 등록 ✨') 및 설명 문구('보관할 물건의 위치와 정보를 기록해 두세요.')를 완전히 삭제**하여, 진입 즉시 첫 화면에서 스크롤 없이 `[물건 이름]`과 `[📍 보관할 위치 지정(3단계)]`에 바로 접근하여 입력할 수 있도록 모바일 수직 뷰포트(Above the fold)를 극대화한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

## 1. [v00183] 주요 변경 및 개선 사항

### 1.1. 배경 및 문제점 해소
- **하단 탭 바와의 정보 중복 제거**:
  - 사용자는 하단 네비게이션 탭에서 `[+ 등록]`을 직접 눌러 진입하므로, 등록 화면임을 100% 인지하고 있습니다.
- **의례적인 가이드 문구 제거**:
  - "보관할 물건의 위치와 정보를 기록해 두세요"라는 문구는 등록 화면이라면 누구나 아는 당연한 사실을 반복하여 실질적인 유익한 정보를 제공하지 못했습니다.
- **수직 뷰포트(Above the fold) 약 80px 확보 및 즉각적인 입력 착수**:
  - 상단 헤더가 차지하던 약 80px의 수직 공간이 사라짐에 따라, 등록 화면에 진입하자마자 **[물건 이름 *] 입력창과 [📍 보관할 위치 지정 (1단계: 공간)] 칩 목록이 스크롤 없이 한눈에** 시원하게 들어옵니다.
  - 진입 즉시 1초 만에 텍스트 타이핑과 위치 선택을 시작할 수 있는 최적의 Frictionless Input UX를 완성했습니다.
