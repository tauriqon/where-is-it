# 🚀 WhereIsIt 토스 네이티브 타이틀 숨김 및 큼직한 브랜드 로고 헤더 탑재 (v00203)

본 문서는 WhereIsIt 미니앱에서 **토스 앱의 고정된 네이티브 헤더 규격(18px)으로 인해 아이콘 크기 확대가 불가능했던 구조적 한계를 해소하기 위해, 토스 네이티브 타이틀을 숨기고(`withTitle: false`) 앱 상단에 28px의 큼직하고 시원한 브랜드 아이콘과 앱 로고 헤더를 전면 배치한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 문제 분석 및 전환 배경

1. **토스 네이티브 헤더의 구조적 한계**:
   - 토스 앱 최상단 네비게이션 바는 토스 네이티브 컴포넌트로 아이콘 틀 크기가 18px로 고정되어 있어, 이미지 여백을 아무리 제거해도 시각적인 크기 확대 효과가 거의 느껴지지 않았습니다.
   - 또한 토스 앱의 로컬 캐시로 인해 이미지 변경사항이 즉각 반영되지 않는 문제가 있었습니다.
2. **해결책 채택 (1안)**:
   - 토스 공식 프레임워크 설정인 `navigationBar: { withTitle: false }`를 적용하여, 토스 상단의 작고 답답한 네이티브 타이틀을 깔끔하게 숨겼습니다.
   - 토스의 뒤로가기(`<`)와 닫기(`... | X`) 기능은 그대로 유지하면서, 바로 아래 우리 화면 상단에 원하는 크기(28px)의 큼직한 브랜드 아이콘과 세련된 '어디 뒀더라?' 타이틀을 직접 배치하기로 결정했습니다.

---

## 2. 주요 구현 및 변경 내역

### 2.1. `granite.config.ts` 네비게이션 바 타이틀 숨김 설정
- `navigationBar: { withTitle: false }`를 선언하여 토스 앱 상단의 18px짜리 앙증맞은 네이티브 텍스트/아이콘을 숨김 처리했습니다:
  ```ts
  navigationBar: {
    withTitle: false,
  },
  ```

### 2.2. 고품질 28px 브랜드 로고 + 앱 타이틀 헤더 신설 (`src/App.tsx`)
- 앱 상단에 토스 스타일의 프리미엄 헤더를 신설했습니다:
  - **좌측**: 28px × 28px의 큼직하고 시원한 집+돋보기 브랜드 아이콘(`borderRadius: 7px`, 부드러운 그림자) + 볼드한 타이틀 `어디 뒀더라?`
  - **우측**: 기존의 `[🏠 내 보관소 / 👨‍👩‍👧‍👦 가족 공유 보관소]` 동기화 상태 뱃지
- 두 요소가 완벽한 수평 균형을 이루며, 기존의 좁고 답답하던 18px 아이콘 대비 2배 이상의 체감 면적과 압도적인 가시성을 제공합니다.
