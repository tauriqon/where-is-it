# 📦 WhereIsIt 퀵 서치 카드 마이크로 모션 1안 vs 2안 비교 구현 (v00177)

본 문서는 WhereIsIt 토스 인앱 미니앱의 홈 탭에서 정제된 토스 블루 캡슐 검색창의 시각적 주목도를 높이기 위해, 가독성을 전혀 해치지 않으면서도 세련되게 시선을 끄는 **[1안: 돋보기 아이콘 마이크로 펄스]**와 **[2안: 은은한 샤인/쉬머 광택]** 두 가지 모션을 홈 화면에 동시 구현하여 비교 체험할 수 있도록 한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

## 1. [v00177] 구현된 두 가지 마이크로 모션 스펙

### 1.1. [1안] 돋보기 아이콘 마이크로 펄스 (Pulse / Bounce)
- **컨셉**: 텍스트 가독성을 100% 지키며, 좌측의 토스 블루 돋보기만 위트 있게 터치를 유도하는 모션.
- **애니메이션 스펙**:
  - CSS 클래스: `.animate-icon-pulse` (`src/index.css`)
  - 3.2초 주기: 평소에는 얌전히 멈춰 있다가, 주기 도래 시 살짝 톡! 튀어오르며(`translateY(-3px)`, `scale(1.22)`, 살짝 갸웃 `rotate(-8deg)`) 귀엽게 주의를 환기한 뒤 제자리 복귀.
  - 가독성 방해 요소가 전혀 없고, 검색창이라는 정체성에 가장 집중된 마이크로 인터랙션.

### 1.2. [2안] 은은한 샤인/쉬머 광택 효과 (Shimmer Sweep)
- **컨셉**: 토스 프리미엄 카드나 결제 완료 화면처럼 카드 표면 위로 부드러운 빛이 스르륵 흐르는 모션.
- **애니메이션 스펙**:
  - CSS 클래스: `.card-shimmer-container`, `.card-shimmer-sweep` (`src/index.css`)
  - 3.6초 주기: 은은한 반투명 블루/화이트 광택 그라데이션(`linear-gradient`) 빔이 왼쪽에서 오른쪽으로 부드럽게 스르륵 스위핑 통과.
  - 텍스트나 아이콘이 흔들리지 않으면서도 하이엔드 핀테크 앱다운 고급스러운 입체감 부여.
