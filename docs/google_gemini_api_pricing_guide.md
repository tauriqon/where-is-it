# 구글 Gemini API 사용 요금 및 물건 인식 운영 가이드

**문서 작성일시**: 2026-11-22  
**대상 모델**: Google Gemini 1.5 Flash (멀티모달 비전 AI)  
**적용 대상**: '아 찾았다! (Where is it?)' 물건 등록 시 사진 기반 물건 이름 자동 인식

---

## 1. 핵심 요약 (TL;DR)

- **무료 제공량**: **하루 1,500회 완전 무료** (분당 최대 15회)
- **초과 시 요금**: 사진 1회 인식당 **약 0.027원** (달러 기준 \$0.00002)
- **1,000회 분석 비용**: **약 27원** (10,000회 분석해도 약 270원)
- **초기/가족 서비스 운영 비용**: **0원 (완전 무료)**
- **결론**: 일일 1,500건 이상의 대규모 트래픽이 발생하기 전까지는 **비용이 일절 발생하지 않으며**, 사용량이 폭증해도 한 달 커피 한 잔 값(약 1,000~2,000원) 미만으로 운영 가능합니다.

## 2. 구글 공식 요금 체계 상세 (Gemini 1.5 Flash)

Google AI Studio 및 Vertex AI의 공식 요금표 기준:

| 항목 | 무료 티어 (Free Tier) | 유료 종량제 (Pay-as-you-go) |
| :--- | :--- | :--- |
| **제공 한도** | **1,500 RPD** (일일 1,500건) / **15 RPM** (분당 15건) | 무제한 (분당 1,000+ RPM) |
| **입력 텍스트/이미지 단가** | 무료 | 100만 토큰당 **\$0.075** (약 100원) |
| **출력 텍스트 단가** | 무료 | 100만 토큰당 **\$0.30** (약 400원) |
| **월 예상 비용** | 하루 1,500건 이하 시 **월 0원** | 10,000건 사용 시 **월 약 270원** |

### 💡 사진 1회 인식당 요금 산출 근거
1. **이미지 토큰 소모**: 사진 1장을 512px 수준으로 전송 시 약 **258 토큰** 고정 소모.
2. **프롬프트 텍스트**: 약 50 토큰 소모.
3. **입력 비용**: `308 토큰 * ($0.075 / 1,000,000) = $0.0000231` (약 0.031원)
4. **출력 비용** (단어 2~3개 반환, 약 10토큰): `10 토큰 * ($0.30 / 1,000,000) = $0.000003` (약 0.004원)
5. **총합**: **1회당 약 \$0.000026 (한화 약 0.035원)**

## 3. 서비스 규모별 월간 예상 비용 시뮬레이션

| 서비스 단계 | 일일 물건 등록 건수 | 월간 총 등록 건수 | 예상 월 AI 비용 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **1단계: 개발 및 가족 공유** | 하루 10 ~ 100건 | 약 1,500건 | **0원 (무료)** | 구글 무료 티어 100% 충족 |
| **2단계: 지인 및 소규모 배포** | 하루 500 ~ 1,000건 | 약 20,000건 | **0원 (무료)** | 무료 한도(1일 1,500건) 이내 |
| **3단계: 일반 공개 (활성 사용자 1,000명)** | 하루 3,000건 | 약 90,000건 | **약 1,200원** | 무료 초과분(1,500건/일)만 과금 |
| **4단계: 대규모 운영 (활성 사용자 10,000명)** | 하루 10,000건 | 약 300,000건 | **약 8,000원** | 극도의 비용 효율성 |

## 4. 비용 낭비 및 폭탄 방지 안전설계 (3중 방어)

1. **조건부 호출 (0원 보호)**:
   - 사용자가 물건 이름을 이미 입력해 둔 경우 AI를 일절 호출하지 않습니다.
2. **클라이언트 초경량 이미지 압축**:
   - 스마트폰 원본 사진(5MB~10MB)을 그대로 보내지 않고, 브라우저 Canvas에서 가로세로 500px 수준의 가벼운 JPEG(약 30~50KB)로 리사이징하여 전송합니다.
   - 네트워크 전송 속도 1초 미만 단축 및 불필요한 토큰 낭비 원천 차단.
3. **구글 클라우드 콘솔 예산 상한선 (Budget Cap)**:
   - 월 최대 허용 예산(예: 월 3,000원 또는 5,000원)을 설정하여, 예기치 못한 트래픽 급증 시에도 설정된 금액을 초과하여 청구되지 않도록 안전장치를 마련할 수 있습니다.

## 5. Gemini API 키 발급 방법 (무료)

1. [Google AI Studio](https://aistudio.google.com/) 접속 및 구글 계정 로그인.
2. 좌측 상단 **[Get API key]** 메뉴 클릭.
3. **[Create API key]** 버튼 클릭 후 프로젝트 선택.
4. 생성된 API 키(`AIzaSy...`) 복사.
5. 앱의 `.env` 파일에 `VITE_GEMINI_API_KEY=복사한_키` 형태로 등록하여 사용.
