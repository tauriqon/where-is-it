## 📋 개요 및 작업 내역

Tauriqon님의 요청에 따라 **공장 초기화 시 위험한 실행 경고 확인(Dangerous Action Confirmation) 개념**을 도입했습니다:
- [공장 초기화 진행] 버튼을 누르면 즉시 초기화되는 대신, 위험 안내와 함께 **현재 내 호칭을 직접 입력하여 검증하는 1단계 바텀시트**가 표시됩니다.
- 입력된 호칭이 정확히 일치할 때만 **기존 2단계 경고 확인 대화창(`window.confirm`)**이 호출되어, 부주의나 오작동으로 인한 데이터 영구 유실을 원천 차단합니다.

## 🔍 상세 개선 내용

### 1. '위험한 실행 경고 확인' 바텀시트 탑재
- **트리거**: 설정 > 애플리케이션 초기화 > `[🔄 공장 초기화 진행]` 클릭
- **경고 메시지 카드**:
  - 빨간색 경고 박스: *"주의: 데이터 완전 초기화"*
  - 상세 안내: *"공장 초기화를 진행하면 기기의 모든 저장소 캐시와 보관소 연동 세션이 삭제되며 처음 상태로 되돌아갑니다. 기존 보관소의 [고유 복구 코드]를 미리 저장해 두지 않은 경우, 기존 물건과 공간 데이터를 다시는 복원할 수 없습니다."*
- **내 호칭 일치 검증**:
  - 확인 안내: *"오작동 및 실수 방지를 위해, 계속 진행하시려면 현재 내 호칭(**{myNickname || '소유자'}**)을 아래 입력창에 정확히 입력해 주세요."*
  - 호칭 입력 필드 (`input-text`) 제공.
  - 엔터 키 지원.

### 2. 2단계 검증 및 실행 파이프라인
1. **1단계 (호칭 불일치 시)**:
   - 햅틱 에러 진동(`error`) 발생.
   - 플로팅 경고 토스트 노출: `"⚠️ 내 호칭이 일치하지 않습니다. '{targetNickname}'을(를) 정확히 입력해 주세요."`
   - 초기화가 즉시 차단되고 바텀시트 유지.
2. **2단계 (호칭 일치 시)**:
   - 햅틱 확인 진동(`basicMedium`) 발생.
   - 바텀시트가 부드럽게 닫힌 후, **기존 경고 확인창**(`window.confirm('기기의 모든 저장소 캐시와 연동 세션을 지우고 공장 초기화하시겠습니까? (새 보관함이 발급됩니다)')`) 노출.
   - 최종 [확인]을 누르면 `supabase.auth.signOut()`, `localStorage.clear()`, `sessionStorage.clear()`, `forceReload(true)`가 안전하게 실행됩니다.
   - [취소]를 누르면 데이터가 안전하게 보존됩니다.
