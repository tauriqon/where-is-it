# 🏷️ WhereIsIt 기존 태그 빠른 선택 칩 및 물건 상세 [설명 및 메모] 전용 카드 신설 (v00198)

본 문서는 WhereIsIt 미니앱에서 **물건 등록 및 수정 시 기존에 사용 중인 태그 목록에서 간편하게 선택(토글)할 수 있는 태그 칩 UI를 탑재하고, 물건 상세 화면에서 눈에 띄지 않거나 누락되어 있던 [설명 및 메모] 항목을 전용 카드 박스로 명확하게 표기하도록 개선한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 개선 배경 및 사용자 피드백

1. **태그 입력 편의성 부족**:
   - 매번 물건을 등록하거나 수정할 때 동일한 태그("공구", "식품", "주방", "상비약" 등)를 직접 타이핑해야 해서 오타 발생 위험이 있고 입력 피로도가 높았습니다.
   - 이미 앱 전체에 등록된 태그 목록을 한눈에 보고 터치 한 번으로 간편하게 추가/해제할 수 있는 빠른 선택 칩이 필요했습니다.

2. **[설명 및 메모] 항목 시각적 인지 불가 문제**:
   - 물건 등록/수정 시 `설명 및 메모`를 입력하여 데이터베이스(`items` 테이블의 `description`)에 정상 저장되었음에도, 상세 팝업에서는 별도의 타이틀이나 테두리 없이 밋밋한 본문 폰트로만 끼워져 있어 눈에 띄지 않았습니다.
   - 특히 설명이 빈 값일 경우 아예 표시되지 않아 사용자가 "설명 및 메모 항목 자체가 화면에서 빠져있다"고 느끼게 되었습니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. 앱 전역 태그 목록 계산 및 Context 제공 (`src/contexts/DataContext.tsx`)
- 전체 `items` 목록에서 중복 없는 태그 집합(`Set`)을 추출하여 오름차순 정렬된 `allTags: string[]`를 `DataContext`의 표준 상태로 제공했습니다.

### 2.2. 물건 등록 폼에 '기존 등록된 태그에서 선택' 칩 UI 탑재 (`src/components/AddTab.tsx`)
- 태그 직접 입력란 바로 아래에 기존 태그들을 알약 형태의 칩 버튼으로 나열했습니다.
- 이미 선택된 태그는 토스 블루 배경과 체크(`Check`) 아이콘으로 하이라이트되며, 미선택 태그는 회색 테두리와 플러스(`Plus`) 아이콘으로 표시되어 직관적으로 토글할 수 있습니다.
- 칩 터치 시 햅틱 피드백(`tickWeak`)을 트리거하여 모바일 네이티브 조작감을 제공합니다.
- 입력 필드 레이블을 "메모 및 세부 정보"에서 "설명 및 메모"로 통일했습니다.

### 2.3. 모든 물건 상세 및 수정 뷰에 기존 태그 선택 칩 탑재
- `src/components/ItemDetailBottomSheet.tsx`
- `src/components/SearchTab.tsx`
- `src/components/ExploreTab.tsx`
- 위 3개 뷰의 물건 정보 수정 모드에서도 동일한 기존 태그 선택 칩을 제공하여 물건 정보 수정 시에도 손쉽게 태그를 구성할 수 있습니다.
- `SearchTab.tsx`의 상단 '자주 찾는 태그'는 `popularTags` (상위 8개)로 깔끔하게 분리하여 중복 선언 충돌을 방지했습니다.

### 2.4. 물건 상세 뷰에 전용 [설명 및 메모] 카드 박스 신설
- `ItemDetailBottomSheet.tsx`, `SearchTab.tsx`, `ExploreTab.tsx` 상세 뷰 공통 적용:
  - `유통기한` 정보 블록 바로 아래에 독립된 `[설명 및 메모]` 섹션 레이블을 신설했습니다.
  - 설명이 있는 경우: 전용 서브틀 카드(`var(--bg-subtle)`, 테두리, `whiteSpace: pre-wrap`, `wordBreak: break-word`)로 감싸 장문의 설명이나 줄바꿈이 포함된 메모도 가독성 높게 표시합니다.
  - 설명이 없는 경우: `"등록된 설명 및 메모가 없습니다."`라는 플레이스홀더를 은은한 그레이톤으로 표기하여 폼 구조의 일관성을 유지했습니다.
