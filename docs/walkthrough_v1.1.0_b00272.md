## 1. 개선 배경 및 목적
- 기존 물건 삭제 시 5초간 화면 하단에 표시되는 Undo(실행 취소) 토스트 메시지가 `"{물건이름}" 물건이 삭제되었습니다.`로 노출되어, 물건 이름 뒤에 '물건'이라는 단어가 중복되어 어색하게 느껴지는 문제를 해결.
- 사용자가 직관적이고 깔끔하게 느낄 수 있도록 `"{물건이름}"이(가) 삭제되었습니다.` 형태로 문구를 개선.
- 물건 이름의 마지막 글자 받침(종성) 유무를 자동으로 판별하여, 받침이 있는 단어("물건이름", "책", "가방" 등)는 `이`, 받침이 없는 단어("모자", "가위", "시계" 등)는 `가`가 자연스럽게 붙도록 한국어 문법을 완벽히 지원.

---

## 2. 세부 변경 사항

### 1) 물건 삭제 완료 Undo 토스트 메시지 문구 개선
- **파일**: `src/contexts/DataContext.tsx`
- **변경 전**: `message: `"${targetItem.name}" 물건이 삭제되었습니다.``
- **변경 후**: `message: `"${targetItem.name}"${marker} 삭제되었습니다.``
- **한국어 조사 자동 판별 로직 (`getSubjectMarker`) 추가**:
  - 한글 유니코드 음절(가~힣)의 종성(받침) 여부를 계산하여 `이` 또는 `가`를 자동 선택.
  - 숫자로 끝나는 경우(0, 1, 3, 6, 7, 8: 받침 있음 ➔ `이` / 2, 4, 5, 9: 받침 없음 ➔ `가`)에도 정확하게 대응.
  - 예시:
    - `"물건이름"이 삭제되었습니다.`
    - `"지갑"이 삭제되었습니다.`
    - `"모자"가 삭제되었습니다.`
    - `"아이폰 16"이 삭제되었습니다.`
