## 🔍 변경 내용 및 상세 개선점 (Detailed Improvements)

### 1. 가족 참여 신청 폼 내 중복 호칭 입력창 제거 (`SettingsTab.tsx`)
- **배경**:
  - 설정 화면 상단에 이미 **[내 호칭 / 이름 변경]** 관리 메뉴가 존재함에도 불구하고, 가족 보관소 참여 신청 폼에 별도의 호칭 입력 필드가 중복 존재하여 사용자의 입력 피로도를 유발함.
- **개선**:
  - '보관소 소유자에게 전달될 내 호칭' 입력 필드를 완전히 제거하고, 공유 코드만 입력하면 원클릭으로 신청할 수 있도록 정돈.
  - 신청 시 기존에 설정해 둔 내 호칭(`localStorage` 및 멤버 프로필)을 자동으로 감지하여 소유자 승인 목록으로 안전하게 전송.
  - 입력창 하단 안내 문구를 보강하여 현재 설정된 내 호칭(`myNickname`)이 소유자에게 전달됨을 명확히 안내.

### 2. 공유 보관소 명칭에 소유자 이름 우선 표시 (`App.tsx`, `SettingsTab.tsx`, `AuthContext.tsx`, `db.ts`)
- **배경**:
  - 기존에는 가족 보관소에 접속하거나 목록을 확인할 때 `wii-k6j2e8`과 같은 난수 형태의 '공유 코드'가 메인 타이틀로 노출되어 누구의 보관소인지 직관적으로 인지하기 어려웠음.
- **개선**:
  - **헤더 전환 버튼 (`App.tsx`)**:
    - 내가 소유한 보관소: `👤 내 개인 보관소 ⌵`
    - 참여한 가족 보관소: `👨‍👩‍👧‍👦 {소유자}님의 보관소 ⌵` (예: `👨‍👩‍👧‍👦 엄마님의 보관소 ⌵`)
  - **보관소 전환 바텀시트 (`App.tsx`)**:
    - 목록 제목을 `g.code` 대신 `{소유자}님의 보관소`로 표시하고, 서브타이틀에 `공유 코드: {code} · 소유자: {owner_name}`을 함께 안내하여 식별성 극대화.
  - **설정 보관소 목록 및 퇴장 안내 (`SettingsTab.tsx`)**:
    - 보관소 목록의 카드 타이틀을 소유자 이름 기반 명칭으로 변경하고 배지와 코드를 깔끔하게 정돈.
    - 퇴장 확인 창에서도 `"{소유자님의 보관소}"(코드: {code})에서 퇴장하시겠습니까?`와 같이 명확한 명칭 제공.
  - **소유자 호칭 데이터 무결성 보강 (`db.ts`, `AuthContext.tsx`)**:
    - `groups.getMyGroups` 및 `groups.get`에서 소유자의 최신 호칭(`user_name`)을 그룹 객체의 `owner_name`으로 신뢰성 있게 매핑.
    - 멤버 변경 및 호칭 갱신 시 `activeGroup.owner_name`과 `myGroups`에 실시간 즉각 반영.
