# 📍 WhereIsIt 보관 위치 바로가기 인터랙션 정밀 분리 및 검색 탭 바로가기 연동 (v00200)

본 문서는 WhereIsIt 미니앱에서 **홈 화면의 물건 상세 바텀시트에서 보관 위치 카드를 터치했을 때 단순 정보 배지인 [등록된 보관 위치 사진이 없습니다] 영역까지 클릭되어 위치 이동이 발생하던 부작용을 해소하고, [탐색] 탭과 [검색] 탭 간의 바로가기 동작 원리를 체계화한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 문제 분석 및 사용자 피드백

1. **[등록된 보관 위치 사진이 없습니다] 클릭 불필요 현상**:
   - 홈 탭의 물건 상세 바텀시트(`ItemDetailBottomSheet.tsx`)에서 보관 위치 카드 전체 최상위 컨테이너에 `onClick` 핸들러가 적용되어 있었습니다.
   - 이로 인해 우측 상단의 `[위치 바로가기 >]` 버튼뿐만 아니라, 하단의 단순 텍스트 안내 배지인 `[등록된 보관 위치 사진이 없습니다]`를 눌렀을 때도 탐색 탭으로 화면이 넘어가버리는 현상이 발생했습니다.
   - 사용자는 "사진이 없다는 안내 메시지를 눌렀는데 왜 화면이 이동하지?"라는 의문을 가질 수밖에 없었습니다.

2. **[탐색] 탭과 [홈] 탭의 차이점 배경**:
   - **홈 탭 / 검색 탭**: 사용자가 탐색 화면 바깥에 있으므로, 이 물건이 저장된 탐색 탭의 해당 공간/수납처/세부위치로 이동하기 위한 `[위치 바로가기 >]` 버튼이 필요합니다.
   - **탐색 탭**: 사용자가 이미 [공간 > 수납처 > 세부위치]를 직접 탐색하여 그 안의 물건 목록을 보고 있는 상태입니다. 즉, 바텀시트의 뒷배경 자체가 이미 그 물건이 있는 보관 위치이므로 바텀시트만 닫으면 바로 그 위치에 머무르게 됩니다. 따라서 별도의 `[위치 바로가기 >]` 버튼을 두지 않았던 것입니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. [위치 바로가기 >] 클릭 영역을 전용 버튼 및 경로로 한정 (`ItemDetailBottomSheet.tsx`)
- 카드 전체에 걸려 있던 클릭 이벤트를 제거하고, **우측 상단의 `[위치 바로가기 >]` 전용 버튼(토스 블루 라이트 배경)과 경로 텍스트 라인**에만 명확하게 네비게이션 액션을 부여했습니다.
- 하단의 `[등록된 보관 위치 사진이 없습니다]` 안내 배지에는 `onClick={(e) => e.stopPropagation()}` 및 `cursor: default`, `userSelect: none`을 적용하여 단순 정보성 배지로 격리했습니다.

### 2.2. 검색 탭(`SearchTab.tsx`)에도 일관된 [위치 바로가기 >] 버튼 탑재
- 검색 결과에서 물건 상세 바텀시트를 열었을 때도 홈 탭과 동일하게 우측 상단 `[위치 바로가기 >]` 버튼을 제공하여, 터치 시 탐색 탭의 해당 위치(공간 > 수납처 > 세부위치)로 바로 이동할 수 있도록 사용자 경험을 일관되게 확장했습니다.
- 검색 탭의 사진 미등록 안내 배지 역시 클릭되지 않도록 안전하게 분리했습니다.

### 2.3. 탐색 탭(`ExploreTab.tsx`) 안내 배지 안전 처리
- 탐색 탭의 사진 미등록 안내 배지에도 `onClick={(e) => e.stopPropagation()}` 및 `cursor: default`를 보강하여 전 화면에서의 일관된 조작감을 보장했습니다.
