# Walkthrough v1.1.0-b00254: 안드로이드 토스 상단 [X] 종료 시 앱 튕김 및 백그라운드 고립 버그 완벽 해결

## 1. 개요 및 배경
- **문제 제기 (Tauriqon님)**:
  > "3번 문제가 해결되지 않았음"
  > (안드로이드폰에서 상단의 ... X 의 [X] 로 앱에서 빠져 나갈려고 하면 토스 전체가 닫힌다. 그런데 백그라운드 를 확인해 보면 토스앱에서 우리앱이 그대로 올라와 있다.)
- **원인 심층 분석**:
  1. **토스 SDK v2.6.1 이상 사양 변경**: 과거 버전과 달리 최신 토스 SDK 및 네이티브 쉘에서는 상단 네이티브 닫기(`[X]`) 버튼 터치 시 토스 자체의 기본 종료 확인 팝업이 제거되었습니다.
  2. **안드로이드 태스크/액티비티 특성**: 개발/테스트 환경(QR 코드 또는 `intoss-private://` 딥링크)에서 실행된 미니앱은 안드로이드 OS상 단독 태스크(Single Task)로 구동됩니다. 미니앱이 사용자 확인 없이 즉시 `finish()`되거나 백그라운드로 이동(`moveTaskToBack`)되면 토스 메인 화면이 아닌 스마트폰 홈 런처로 튕겨 나가게 됩니다.
  3. **b00253 오판 조치 수정**: `b00253`에서 `homeEvent` 리스너를 제거했으나, 이로 인해 상단 `[X]` 터치가 웹뷰에서 전혀 가로채지지 않고 네이티브 쉘의 기본 동작(홈 런처로 즉시 튕김)으로 바로 이어져 동일한 문제가 재발하였습니다.
  4. **백그라운드 스냅샷 및 고립**: 종료 확인 팝업 없이 튕길 경우 안드로이드 멀티태스킹(최근 실행 앱) 목록에 WhereIsIt의 화면이 그대로 캡처되어 남아있고, 이를 탭하면 종료되지 않은 채 복구되는 현상이 발생했습니다.

## 2. 해결 및 개선 상세

### 2.1. 토스 네이티브 `homeEvent` 정밀 인터셉트 및 종료 확인 모달 연동 (`src/App.tsx`)
- 토스 SDK의 `graniteEvent.addEventListener('homeEvent')`를 다시 등록하되, **단순 `closeView()` 즉시 호출이 아닌 커스텀 종료 확인 모달(`setIsExitModalOpen(true)`)**을 띄우도록 전면 개편했습니다.
- 사용자가 실수로 상단 `[X]`를 터치하더라도 앱이 튕기지 않고 **"아 찾았다!를 종료할까요?"** 토스 스타일 모달이 뜨며, `[닫기]`를 누르면 안전하게 앱에 머무릅니다.

### 2.2. Event Callback Ref 패턴 적용 (구독 타이밍 누락 방지)
- `handleHomeActionRef` 및 `handleBackActionRef`를 도입하여 컴포넌트 마운트 시점에 이벤트 리스너를 단 1회 안전하게 등록하고, 탭 전환 시에도 구독이 해제/재등록되는 빈틈 없이 항상 최신 탭 상태를 반영하도록 보장했습니다.

### 2.3. 토스 메인 홈 복귀 및 안전 종료 파이프라인 (`handleConfirmExit`)
- 사용자가 종료 모달에서 `[종료하기]`를 확정할 경우:
  1. `setIsExiting(true)`를 활성화하여 화면을 "종료하는 중..." 클린 뷰로 전환 (안드로이드 멀티태스킹 스냅샷에 앱 UI가 살아있는 채로 남는 현상 방지).
  2. `openURL('supertoss://home')`을 호출하여 토스 메인 홈 화면으로 안전하게 초점을 복귀.
  3. `Screen.close()` (폴백: `closeView()`)를 순차 호출하여 미니앱 웹뷰를 완전히 종료.
