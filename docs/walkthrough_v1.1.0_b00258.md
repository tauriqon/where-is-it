## 2. 변경 내용 및 상세 구현

### 2.1. 공유 메시지 템플릿 간소화 (`SettingsTab.tsx`)
- 기존의 복잡하고 긴 링크/가이드 문구를 전면 제거하고, Tauriqon님께서 요청하신 3줄의 명확하고 간결한 형식으로 개편하였습니다:
  ```text
  [아 찾았다!]  [보내는 사람 호칭] 보관소 공유 코드 입니다.
  설정의 가족 동기화 에서 입력후 참여 신청하기를 눌러주세요.
  코드 : wii-xxxxxx
  ```

- **보내는 사람 호칭 동적 주입**:
  - 설정에 등록된 내 호칭(`myNickname`, 예: `Ed.Kim`, `엄마`, `아빠` 등)을 자동으로 가져와 삽입합니다.
