## 🔍 변경 내용 및 상세 개선점 (Detailed Improvements)

### 1. 보관소 전환 목록 카드 정보 간소화 (`SettingsTab.tsx`)
- **이전 상태**:
  - `보관소 목록 (사용 보관소 전환)` 카드마다 타이틀 하단에 `공유 코드: wii-xxxxxx · 생성일: 2026. 11. XX` 텍스트가 노출되어 카드가 세로로 길어지고 시각적 복잡도를 높임.
- **개선 후**:
  - 빨간줄로 표시해 주신 해당 서브 텍스트 라인을 완전히 삭제.
  - 보관소 명칭(`내 개인 보관소` 또는 `Ed.Kim님의 보관소`)과 식별 배지(`내 보관소`, `소유자 이름`), 그리고 우측의 액션 버튼(`[전환]` 또는 `[사용 중] [휴지통]`)이 단일 라인으로 깔끔하게 정렬되어 한눈에 들어오는 토스 스타일의 컴팩트 카드 레이아웃 완성.

### 2. '내 보관소 참여 멤버' 조건부 표시 적용 (`SettingsTab.tsx`)
- **이전 상태**:
  - `ownerGroup` 대상을 활성 그룹(`activeGroup`) 기준으로 잘못 참조하여, 가족 보관소에 참여한 초대 기기(예: `AppTotal`)에서도 소유자의 멤버 목록이 `내 보관소 참여 멤버 (2명)`이라는 명칭으로 상시 노출되는 혼선 발생.
- **개선 후**:
  - `내 보관소`의 기준을 항상 현재 사용자가 소유한 개인 보관소(`myOwnGroup = myGroups.find(g => g.owner_id === user.id)`)로 명확히 한정.
  - 내 개인 보관소에 다른 가족 멤버(`familyMembers`)가 1명 이상 실제로 참여하여 공유 중인 경우에만 `내 보관소 참여 멤버 ({N}명)` 카드가 노출되도록 개선.
  - 초대받은 가족 기기이거나 내 개인 보관소를 다른 사람에게 공유하지 않은 상태에서는 해당 보라색 박스 영역이 전혀 나타나지 않아 화면이 한결 깔끔해짐.
