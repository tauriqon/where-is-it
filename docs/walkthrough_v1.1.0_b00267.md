# 아 찾았다! (Where is it?) - v1.1.0 (b00267) 변경 내역 및 Walkthrough

**문서 생성일시**: 2026-11-21  
**대상 버전**: `v1.1.0 (b00267)`  
**작업 요약**: 설정 상단 고정 헤더 블러 효과를 최소 수준(`blur(4px)`)으로 축소하여 스크롤 통과 콘텐츠의 선명도 극대화 및 타이틀 소프트 텍스트 섀도우 보강

---

## 1. 개선 배경 및 목적
- 90% 투명도 상태에서 강한 블러(기존 16px)로 인해 뭉개지던 배경을, 사용자의 요청에 따라 블러 효과를 최소한(`blur(4px)`)으로 낮추어 밑으로 지나가는 콘텐츠가 실제 투명 유리처럼 훨씬 더 뚜렷하고 선명하게 보이도록 개선.

---

## 2. 세부 변경 사항

### 1) 상단 고정 헤더 최소 블러 적용 (`renderStickyHeader`)
- **파일**: `src/components/SettingsTab.tsx`
- **블러 필터 조정**:
  - 기존: `backdropFilter: 'blur(16px)'`
  - 변경: `backdropFilter: 'blur(4px)'` (`WebkitBackdropFilter: 'blur(4px)'`)
- **배경색 유지**: `rgba(255, 255, 255, 0.10)` (90% 투명도 유지)
- **타이틀 가독성 안전장치 추가**:
  - 블러가 4px로 최소화됨에 따라 스크롤 중 밑의 글씨가 타이틀과 겹칠 때 가독성이 떨어지지 않도록, 타이틀과 서브타이틀에 소프트 화이트 텍스트 섀도우(`textShadow: '0 1px 3px rgba(255, 255, 255, 0.8)'`)를 은은하게 부여하여 선명도와 가독성을 동시 확보.
