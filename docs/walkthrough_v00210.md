# 📐 WhereIsIt 물건 수정 바텀시트 내 공간/수납처/세부위치 간편 직접 추가 기능 구현 (v00210)

본 문서는 WhereIsIt 미니앱에서 **물건 수정 바텀시트에서 기존 위치 목록 선택뿐만 아니라, 새로운 공간·수납처·세부 위치를 바텀시트를 벗어나지 않고 즉시 직접 추가하고 자동 선택되도록 구현한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 개선 배경 및 사용자 피드백

1. **상황 및 사용자 피드백**:
   - "이 화면에서 위치 수정 카드에서 기존 위치 정보는 선택이 가능한데, 만일 새로운 공간, 수납처, 세부 위치 를 추가하려면?"
   - "하자" (1안: 바텀시트 내 직접 간편 추가 및 자동 선택 확정)
2. **해결 과제**:
   - 기존에는 이미 생성된 위치들만 선택할 수 있어, 물건을 새로운 방이나 수납장으로 이동시키고 싶을 때 수정을 중단하고 설정 탭으로 이동해야만 했습니다.
   - 설정 탭으로 이동하면 바텀시트가 닫히면서 작성 중이던 물건 정보(이름, 사진, 수량, 태그 등)가 유실되는 문제가 있었습니다.
   - 따라서 **수정 중인 물건 내용을 100% 안전하게 유지하면서, 바텀시트 내에서 인라인으로 새 위치를 추가하고 추가 즉시 자동 선택**되도록 개선했습니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. 3단계 위치 수정 카드 내 간편 추가 버튼 및 인라인 입력창 구현
- **1단계: 공간**:
  - `[+ 새 공간]` 버튼 클릭 시 인라인 입력창 오픈
  - 이름 입력 후 [추가] 또는 Enter 입력 시 `createSpace` 호출 ➔ **새 공간이 즉시 생성 및 자동 선택**
- **2단계: 수납처** (공간 선택 시 활성화):
  - `[+ 새 수납처]` 버튼 클릭 시 인라인 입력창 오픈
  - 이름 입력 후 [추가] 또는 Enter 입력 시 선택된 공간 하위에 `createStorage` 호출 ➔ **새 수납처 즉시 생성 및 자동 선택**
- **3단계: 세부 위치** (수납처 선택 시 활성화):
  - `[+ 새 위치]` 버튼 클릭 시 인라인 입력창 오픈
  - 이름 입력 후 [추가] 또는 Enter 입력 시 선택된 수납처 하위에 `createSection` 호출 ➔ **새 세부 위치 즉시 생성 및 자동 선택**

### 2.2. 모바일 친화적 인라인 UX 및 안정성 보장
- `window.prompt` 같은 웹뷰 취약 팝업을 배제하고, 깔끔한 인라인 입력 필드(`input-text`)와 토스 블루 버튼을 적용했습니다.
- 엔터키(`Enter`) 입력 대응 및 햅틱 피드백(`triggerHaptic('success')`)을 연동하여 모바일 입력 편의성을 극대화했습니다.
- 홈(`ItemDetailBottomSheet.tsx`), 탐색(`ExploreTab.tsx`), 검색(`SearchTab.tsx`)의 3개 탭에 완벽하게 동일한 규격으로 동시 적용되었습니다.
