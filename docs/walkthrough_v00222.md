# Walkthrough v00222 - 바텀시트 수정 모드 뒤로가기(<) 경고창 및 닫기(X) 안전 복원 메커니즘 구축

## 1. 개요 (Overview)
* **목적**: 바텀시트에서 물건 정보를 수정 중일 때, 사용자의 실수로 인한 데이터 유실을 방지하고 작업 흐름을 안전하게 보존합니다.
* **사용자 요청 사항**:
  > "바텀시트 수정중 입력후 저장하지 않고 < 를 눌러 뒤로 갈때는 경고창을, X를 눌러 빠져 나갈경우 안전복원메카니즘을 적용할 수 있을까?"

---

## 2. 주요 구현 내용 (Key Implementation)

### 2.1 < 뒤로가기 클릭 시 이탈 방지 경고창 제공
* **동작 시점**:
  1. 기기/토스 제스처 및 하드웨어 뒤로가기(`<` backEvent) 실행 시
  2. 바텀시트 헤더 좌측에 새로 추가된 `<` 뒤로가기 버튼 클릭 시
  3. 수정 폼 하단의 `[취소]` 버튼 클릭 시
* **동작 방식**:
  * 사용자가 물건 이름, 수량, 메모, 태그, 보관 위치(공간/수납처/구분), 유통기한, 사진 등을 수정한 내역이 있는지 기존 물건 정보와 실시간 비교(`hasUnsavedChanges`).
  * 변경 사항이 감지된 상태에서 `<` 또는 `[취소]`를 누르면 확인창(`window.confirm`)을 표시:
    > **"수정 중인 내용이 있습니다. 변경사항을 저장하지 않고 나가시겠습니까?"**
  * **[취소] 클릭**: 현재 수정 화면에 그대로 머무릅니다.
  * **[확인] 클릭**: 임시 저장본(`wii_edit_item_draft_${itemId}`)을 깨끗하게 삭제하고, 원래 정보로 폼을 리셋한 뒤 안전하게 상세 화면으로 복귀합니다.
  * 변경 사항이 없는 경우에는 확인창 없이 바로 상세 화면으로 이동합니다.

### 2.2 X 닫기 시 100% 안전 복원 메커니즘 (Safe Auto-Restore)
* **동작 시점**:
  1. 바텀시트 헤더 우측의 `✕` 닫기 버튼 클릭 시
  2. 바텀시트 바깥 어두운 배경(딤) 터치 시
  3. 토스 앱 최상단 헤더의 `[··· ✕]` 비상 종료 버튼으로 앱이 닫힐 때
* **동작 방식**:
  * **실시간 영구 저장 (`localStorage`)**:
    * 사용자가 내용을 수정하는 즉시 `wii_edit_item_draft_${itemId}` 키로 로컬 스토리지에 자동 저장됩니다.
    * `✕` 버튼으로 시트가 닫히거나 앱이 종료되어도 임시 저장본이 안전하게 보존됩니다.
  * **재진입 시 자동 복원**:
    * 해당 물건의 상세/수정 바텀시트를 다시 열면, 로컬 스토리지에 보관된 임시 수정본을 감지하여 **자동으로 수정 모드(`isEditing: true`)로 진입하고 모든 수정 필드를 100% 복원**합니다.
    * 수정 폼 최상단에 복원 안내 배너 표시:
      > `📝 이전에 수정 중이던 내용이 복원되었습니다. [원래대로]`
    * `[원래대로]` 버튼을 누르면 확인 후 임시 저장본을 지우고 원래 물건 정보로 초기화할 수 있습니다.
  * **수정 완료 시 자동 소거**:
    * 수정을 정상적으로 마치고 `[수정 완료]`를 누르면 DB 저장과 함께 로컬스토리지의 임시 저장본이 안전하게 자동 삭제됩니다.

### 2.3 적용 컴포넌트 범위
* `src/components/ItemDetailBottomSheet.tsx` (홈 화면 등 공통 상세 시트)
* `src/components/ExploreTab.tsx` (탐색 탭 물건 상세 시트)
* `src/components/SearchTab.tsx` (검색 탭 물건 상세 시트)
* 전 탭에서 동일한 안전 규칙과 복원 메커니즘이 빈틈없이 작동합니다.
