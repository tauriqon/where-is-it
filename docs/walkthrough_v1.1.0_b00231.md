## 🔍 원인 분석 및 해결

1. **상태 미동기화 및 리로드 부재**:
   - 기존에는 복구 성공 후 화면 새로고침 없이 단순 서브페이지 이동(`onChangeSubPage('main')`)만 수행하여, 리액트 메모리상 `DataContext`가 초기화 시 생성되었던 빈 보관소(`wii-glemr5`)를 계속 참조하고 있었습니다.
   - **해결**: 복구 완료 즉시 안내 알림 후 `forceReload(true)`를 호출하여 브라우저/웹뷰 전체가 복원된 보관소(`wii_active_group_id`)를 기준으로 클린 리로드되도록 수정했습니다.
2. **복구 코드 표시 타깃 수정**:
   - `SettingsTab`에서 내 복구 코드를 조회할 때 `ownerGroup?.code`를 우선하여, 초기화 시 생성된 임시 빈 그룹의 코드가 계속 표시되던 문제를 `activeGroup?.code` 우선으로 변경하여 항상 현재 활성 복원 보관소의 코드가 정확히 표시되도록 바로잡았습니다.
3. **임시 빈 그룹 자동 정리**:
   - 초기화 직후 신규 발급되었던 아이템 0개의 임시 보관소 멤버십을 자동 정리하여 계정 혼선과 잔존을 방지했습니다.
