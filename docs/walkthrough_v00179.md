## 1. [v00179] 주요 변경 및 개선 사항

### 1.1. 배경 및 문제점 해소
- **토스 네이티브 헤더 타이틀 중복 해소**:
  - 화면 최상단 네이티브 헤더에 이미 `< 어디 뒀더라?`가 고정 노출되고 있음에도, 본문 시작부에 커다란 `<h1>어디 뒀더라? 🔍</h1>`가 반복 표시되던 어색함을 완전 해소.
- **보관 통계 위젯과의 정보 중복 해소**:
  - "집안에 N개의 소중한 물건들이 안전하게 보관되어 있어요"라는 텍스트 문장이 바로 밑의 `[총 물건 종류: N종]` 볼드 숫자 위젯과 100% 동일한 정보를 중복 전달하던 군더더기를 제거.
- **모바일 수직 뷰포트(Above the fold) 100px 확보**:
  - 웰컴 배너가 차지하던 약 90~100px의 수직 공간이 사라짐에 따라, **[보관 통계 위젯] ➔ [펄스 퀵 서치 바] ➔ [유통기한 도래 물건]**이 스크롤 없이 첫 화면에 시원하게 쏙 들어오는 진정한 프리미엄 대시보드 레이아웃 구축.

### 1.2. 코드 수정 내역
- **대상 파일**: `src/components/HomeTab.tsx`
- `<div style={{ marginBottom: '20px', padding: '4px 0' }}>` 웰컴 배너 블록 전면 삭제.
- 홈 화면 진입 시 최상단에 바로 `[보관 통계 위젯]`이 산뜻하게 배치되도록 정돈.
