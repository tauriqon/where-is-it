# 🧭 WhereIsIt 위치 탐색 탭 헤더 슬림화 및 브레드크럼 통합·확대 (v00186)

본 문서는 WhereIsIt 미니앱의 **`위치 탐색(ExploreTab)`** 탭에서 중복되던 대형 제목(`공간 선택`, `[<] xxx의 수납처`)과 뒤로가기 버튼 줄을 제거하고, 상단 **`브레드크럼(Breadcrumb)`**을 단일 네비게이션 헤더로 통합·확대하여 화면 공간을 극대화하고 미니멀한 UI를 완성한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. [v00186] 주요 변경 및 개선 사항

### 1.1. 중복 헤더 줄 제거 및 브레드크럼 단일화
기존에는 상단에 브레드크럼(`전체 > 거실 > 옷장`)과 그 아래 별도의 제목 줄(`[<] 거실의 수납처`)이 2단으로 나열되어 있어, 같은 위치 정보가 중복되고 모바일 화면 상단 공간을 불필요하게 많이 차지하고 있었습니다.

- **기존 2단 헤더 구조**:
  - 1행: 브레드크럼 (`전체 > 거실 > ...`)
  - 2행: `[<] 뒤로가기 버튼` + `[xxx의 수납처]` (24px 볼드 대형 제목)
- **개선된 단일 헤더 구조**:
  - 2행의 제목과 `[<]` 버튼을 전면 제거
  - 1행의 **브레드크럼 자체를 메인 네비게이션 헤더로 승격·통합**
  - 카드 목록이 화면 상단으로 시원하게 올라와 한 번에 더 많은 공간/수납처/물건을 볼 수 있도록 최적화

---

### 1.2. 브레드크럼 시인성 및 터치성 대폭 강화
제목이 사라진 대신 브레드크럼이 명확한 헤더 역할을 수행할 수 있도록 크기와 가독성을 대폭 상향했습니다.

| 구분 | 기존 규격 (v00185) | 변경 규격 (v00186) | 상세 내용 |
| :--- | :--- | :--- | :--- |
| **현재 활성 단계 (최하위)** | `15px`, fontWeight `600` | **`20px`, fontWeight `700` (Bold)** | 메인 타이틀 역할을 하도록 볼드하고 큼직하게 강조 |
| **상위 단계 (클릭 가능한 부모)** | `15px`, fontWeight `500` | **`17px`, fontWeight `600` (SemiBold)** | 터치 가능한 경로 링크로서의 시인성 확보 |
| **경로 구분자 (`>`)** | `size={14}` | **`size={16}`** | 계층 이동 기호 선명도 향상 |
| **이모지/사진 썸네일** | `size={14}` / `24px` | **`size={18}` / `24px`** | 가구/공간 아이콘 인지성 향상 |
| **텍스트 말줄임 한도 (`maxWidth`)** | `90px` | **`130px`** | 긴 이름(예: `김치냉장고`, `안방 화장대`)도 잘림 없이 노출 |
| **터치 반응 영역** | 인라인 기본 | **`padding: 4px 6px`, `borderRadius: 6px`** | 엄지손가락으로 쉽게 탭하여 상위 단계 이동 가능 |

---

### 1.3. 뒤로가기 네비게이션 경험
- **상위 단계 탭**: 브레드크럼의 상위 위치(예: `전체 위치`, `거실`)를 가볍게 탭하면 즉시 해당 상위 단계로 돌아갑니다.
- **네이티브 제스처 유지**: 토스 인앱 및 스마트폰 뒤로가기(스와이프/하드웨어 뒤로가기 키) 연동(`registerBackHandler`)은 그대로 완벽하게 동작합니다.
