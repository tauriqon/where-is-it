## 🛠️ 해결된 핵심 이슈 및 모바일 태그 UX 개선

### 1. 안드로이드/모바일 키보드에서 엔터키 대신 "다음"으로 표시되는 현상 해결
- **문제 현상**:
  - 안드로이드(삼성 키보드, Gboard 등)에서 물건 수정/등록 시 태그를 입력할 때, 키보드 우측 하단 키가 '엔터'가 아닌 **[다음]**으로 표시됩니다.
  - 사용자가 [다음] 키를 누르면 엔터 이벤트가 발생하는 것이 아니라 다음 폼 필드('설명 및 메모')로 포커스가 이동하여, 기껏 입력한 태그가 배지로 등록되지 않고 인풋창에 방치되는 현상이 발생했습니다.
- **근본 원인**:
  - 모바일 웹 브라우저는 단일 `<input>` 바로 뒤에 다른 입력창(메모 textarea)이 있을 경우, 기본 IME 액션을 `actionNext`("다음")로 지정하여 키보드를 렌더링하기 때문입니다.
- **해결책**:
  1. **물리적 `[+ 추가]` 터치 버튼 배치**:
     - 엔터키에 의존하지 않고, 태그 입력창 바로 우측에 원터치 `[추가]` 버튼을 나란히 배치했습니다.
     - 글자를 입력하면 활성화되며 터치 즉시 배지 태그로 확정 등록됩니다.
  2. **모바일 키보드 힌트 `enterKeyHint="done"` 적용**:
     - 모바일 브라우저에게 이 입력창의 액션이 '완료'임을 명시하여, 키보드 우측 하단이 '다음' 대신 **'완료' 또는 '엔터(✓)'** 모양으로 노출되도록 유도했습니다.
  3. **포커스 아웃(`onBlur`) 자동 커밋 (Auto-Commit)**:
     - 사용자가 엔터나 추가 버튼을 깜빡하고 다른 곳을 터치하거나 키보드의 [다음]을 눌러 다음 칸으로 넘어가더라도, 인풋창에 써둔 글자가 날아가지 않고 **자동으로 태그 목록에 등록**됩니다.
  4. **저장/수정완료 시 미등록 태그 누락 방지 안전망**:
     - `handleSaveEdit` 및 `handleSubmit` 실행 시, 인풋창에 아직 배지로 등록되지 않은 글자가 남아있다면 이를 최종 저장할 태그 목록에 자동으로 병합하여 100% 무손실 저장을 보장합니다.
