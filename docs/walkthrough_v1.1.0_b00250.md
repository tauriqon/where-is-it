## 🔍 변경 내용 및 상세 디자인 적용 (UI & Architectural Changes)

### 1. 최상단 헤더 보관소 전환 버튼 디자인 업그레이드 (`App.tsx`)
- **이전 상태**:
  - 회색 배경 캡슐 알약 형태(`badgeBg: #f1f3f5`, 1px border)에 작은 점(`dotColor`)과 텍스트(`• 🏠 내 보관소 ⌵`)로 다소 투박하게 표시됨.
- **개선 후**:
  - 홈 탭에서 호평받은 깔끔하고 선명한 화이트 카드 버튼 스타일 적용:
    - 배경: `#ffffff`
    - 테두리: `1.5px solid var(--border-medium)`
    - 여백 및 곡률: `padding: 6px 14px`, `border-radius: 20px`
    - 그림자: `0 1px 3px rgba(0, 0, 0, 0.03)`
    - 폰트: `fontSize: 13px`, `fontWeight: 700`, `color: var(--text-primary)`
    - 내용 구성: 이모지 아이콘(`👤` 또는 `👨‍👩‍👧‍👦`) + 보관소명(`내 개인 보관소` 또는 공유 코드) + `ChevronDown` 화살표
  - 불필요했던 인디케이터 점(`dotColor`) 및 투박한 회색 배경을 제거하여 토스 디자인 시스템 특유의 미니멀하고 단정한 룩앤필 완성.

### 2. 홈 탭(HomeTab) 내 중복 영역 및 불필요 버튼 제거 (`HomeTab.tsx`)
- **중복 바 제거**:
  - 홈 탭 최상단에 위치하던 `[👤 내 개인 보관소 ⌵]` 및 `보관소 관리 >` 바로가기 바를 완전히 제거.
  - 이제 홈 탭 진입 시 보관 통계 위젯(`총 물건 종류`, `보관 공간`, `등록된 수납처`)이 바로 첫머리에 시원하게 펼쳐지도록 레이아웃 정돈.
- **코드 정리 (Clean-up)**:
  - `HomeTabProps`의 `onOpenWorkspaceSwitch` prop 제거.
  - 사용되지 않는 `useAuth`, `ENABLE_FAMILY_SYNC`, `ChevronDown` import 및 관련 상태 변수 정리.
