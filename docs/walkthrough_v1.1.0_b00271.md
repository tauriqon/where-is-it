## 1. 개선 배경 및 목적
- **위치 선택 시스템 UI 중복 제거**:
  - 물건 등록 화면(`AddTab.tsx`)의 `1단계: 공간`, `2단계: 수납처`, `3단계: 세부 위치` 각 라벨 우측에 위치하던 `+ 새 공간 추가`, `+ 새 수납처 추가`, `+ 새 세부위치 추가` 버튼이 각 셀렉트박스 드롭다운 하단의 `새 공간/수납처/세부위치 추가하기` 항목과 중복되어 레이아웃이 복잡해지는 문제를 해결.
  - 상단 텍스트 버튼을 제거하여 라벨 영역을 깔끔하게 정리하고, 사용자가 드롭다운 메뉴 안에서 일관된 흐름으로 신규 위치를 추가할 수 있도록 통합.
- **기존 등록된 태그 다량 증가 대비 구조 혁신**:
  - 등록된 물건 수가 많아질수록 `기존 등록된 태그에서 선택` 영역의 칩 수가 기하급수적으로 늘어나 화면 하단 메모 입력창 및 등록 버튼이 밀려나는 문제를 예방.
  - 8개 초과 시 상위 8개만 우선 노출하고 `+N개 더보기` 및 `전체보기/간략히` 토글 제공.
  - 태그 입력창(`tagInput`)에 타이핑 시 기존 태그가 즉각 실시간 필터링되는 스마트 검색 기능 추가.
  - 선택된 태그가 항상 앞쪽에 정렬되어 손쉽게 확인 및 해제 가능.
  - 펼침 상태에서는 최대 높이(`maxHeight: 135px`) 스크롤 컨테이너를 적용하여 50~100개 이상의 태그가 존재해도 화면 레이아웃이 흐트러지지 않도록 방어.

---

## 2. 세부 변경 사항

### 1) 위치 선택 3단계 라벨 우측 중복 버튼 제거
- **파일**: `src/components/AddTab.tsx`
- **변경 내용**:
  - `1단계: 공간 *` 라벨 우측의 `<Plus size={14} /> 새 공간 추가` 버튼 제거.
  - `2단계: 수납처 *` 라벨 우측의 `<Plus size={14} /> 새 수납처 추가` 버튼 제거.
  - `3단계: 세부 위치 *` 라벨 우측의 `<Plus size={14} /> 새 세부위치 추가` 버튼 제거.
  - 각 드롭다운 목록 최하단에 상시 제공되는 `새 공간/수납처/세부위치 추가하기` 항목을 통해 직관적이고 통일된 진입 동선 유지.

### 2) 기존 등록된 태그 선택 UI/UX 고도화
- **파일**: `src/components/AddTab.tsx`, `src/components/ItemDetailBottomSheet.tsx`, `src/components/ExploreTab.tsx`, `src/components/SearchTab.tsx`
- **적용 내용**:
  - **스마트 검색 필터링**: 태그 입력란에 키워드를 입력하면, 해당 검색어를 포함하는 기존 태그만 즉각 필터링되어 노출. 일치하는 태그 터치 시 태그가 자동 추가되고 검색창이 초기화됨.
  - **선택된 태그 우선 정렬**: 이미 선택된 태그들이 목록의 최상단에 먼저 노출되어 편리하게 확인 및 해제 가능.
  - **간략히 보기 모드 (기본)**:
    - 8개 이하인 경우: 깔끔하게 전체 태그 노출.
    - 8개 초과인 경우: 상위 8개만 노출 + 우측 상단 `전체보기 (N)` 버튼 및 마지막에 `+N개 더보기` 뱃지 노출.
  - **전체 펼침 모드 (스크롤 뷰)**:
    - `전체보기` 또는 `+N개 더보기` 터치 시 최대 높이 `135px`의 전용 스크롤 박스로 매끄럽게 확장되어 수십~수백 개의 태그도 안정적으로 탐색 가능.
    - 우측 상단 `간략히` 버튼으로 언제든지 원복 가능.
  - **수정 및 탐색 시트 안전장치**:
    - `ItemDetailBottomSheet.tsx`, `ExploreTab.tsx`, `SearchTab.tsx`의 태그 선택 영역에도 `maxHeight: 120px` 스크롤 뷰를 적용하여 바텀시트가 과도하게 늘어나는 현상 방지.
