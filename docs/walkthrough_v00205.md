# 📐 WhereIsIt 검색 및 설정 화면 제목 폰트 크기 표준화 (v00205)

본 문서는 WhereIsIt 미니앱에서 **검색 화면([검색])과 설정 화면([설정])의 상단 제목 폰트 크기가 다른 화면들의 제목(20px)에 비해 유독 커 보이던(24px) 불일치를 해소하고, 전 화면의 주요 타이틀을 20px 볼드로 완벽하게 통일한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 개선 배경 및 사용자 피드백

1. **상황 및 사용자 피드백**:
   - "검색화면과 설정화면의 위의 제목 [검색], [설정]의 폰트 사이즈가 다른 화면보다 커보인다. 다른 화면의 크기와 통일해줘."
2. **원인 분석**:
   - 홈 탭 헤더(`어디 뒀더라?`: 20px), 탐색 탭 브레드크럼(`전체 위치`: 20px), 설정 서브페이지 헤더(`보관위치 관리` 등: 20px) 등 주요 타이틀은 모두 20px 규격으로 정돈되어 있었습니다.
   - 반면 `SearchTab.tsx`의 [검색]과 `SettingsTab.tsx`의 [설정]은 `.h1-title`(24px) 클래스를 사용하여 다른 화면보다 4px 더 크게 렌더링되고 있어 시각적 균형이 맞지 않았습니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. 검색 화면 [검색] 제목 폰트 크기 통일 (`SearchTab.tsx`)
- 기존 `<h1 className="h1-title">검색</h1>`(24px)을 `<h2 className="h2-title" style={{ fontSize: '20px', fontWeight: '700', marginBottom: '16px' }}>검색</h2>`(20px)로 변경하여 통일감을 부여했습니다.

### 2.2. 설정 화면 [설정] 제목 폰트 크기 통일 (`SettingsTab.tsx`)
- 기존 `<h1 className="h1-title">설정 <Settings size={22} ... /></h1>`(24px)을 20px 폰트와 20px 아이콘으로 정돈하여, 다른 화면과 동일한 시각적 무게감을 갖도록 개선했습니다.
