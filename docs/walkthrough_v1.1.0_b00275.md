# 아 찾았다! (Where is it?) - v1.1.0 (b00275) 변경 내역 및 Walkthrough

**문서 생성일시**: 2026-11-22  
**대상 버전**: `v1.1.0 (b00275)`  
**작업 요약**: 발급된 구글 Gemini API 키 연동 및 AI 비전 기반 물건 대표 이름 자동 추천/입력 파이프라인 정식 활성화

---

## 1. 개선 배경 및 목적
- Tauriqon님께서 직접 발급해 주신 Google Gemini API 키를 환경변수에 등록하여, 물건 사진 등록 시 실시간으로 사진 속 물건을 인식하고 대표 명사를 [물건 이름] 필드에 자동 입력해 주는 AI 비전 기능을 정식 가동.
- 구글 최신 Gemini 멀티모달 모델(`gemini-3.5-flash-lite`, `gemini-3.5-flash` 등)을 지원하도록 모델 폴백(Fallback) 구조를 강화하여 높은 안정성과 응답 속도(1초 이내) 확보.

---

## 2. 세부 변경 사항

### 1) Google Gemini API 키 환경변수 연동
- **파일**: `.env`
- 발급받은 Gemini API 키를 `VITE_GEMINI_API_KEY`에 등록하여 클라이언트에서 안전하게 AI 비전 서비스를 사용할 수 있도록 활성화.

### 2) 모델 호출 안정성 및 폴백(Fallback) 강화
- **파일**: `src/services/aiVision.ts`
- 구글의 최신 모델 라인업에 맞추어 `gemini-3.5-flash-lite` ➔ `gemini-3.5-flash` ➔ `gemini-2.5-flash` ➔ `gemini-1.5-flash` 순으로 자동 폴백되도록 개선.
- 테스트 결과: 이미지 분석 요청에 대해 정확한 물건 이름(한국어 대표 명사)이 초고속으로 반환됨을 확인.

### 3) AddTab 실시간 시각 피드백 연동
- 사진 등록 시 이름이 비어있으면 이름 입력창에 `🤖 AI가 사진 속 물건을 인식하고 있어요...` 플레이스홀더 및 스피너가 표시되고, 분석 완료 시 토스트 알림(`🤖 사진 분석: "OO"(으)로 자동 입력되었습니다.`)과 함께 햅틱 피드백이 발생.

## 3. 검증 결과
- `gemini-3.5-flash-lite` 엔드포인트 curl 실시간 테스트 완료 (인식 및 한국어 단어 응답 정상).
- `npm run build` 빌드 검증 성공 (`family-inventory.ait` 패키징 정상 완료).
- 이제 스마트폰에서 물건 사진을 촬영하거나 앨범에서 선택하면, 비어있는 물건 이름 칸에 해당 물건의 이름이 자동으로 채워집니다.
