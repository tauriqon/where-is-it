# 📐 WhereIsIt 화면별 타이틀 [아이콘] [제목] 통일화 (v00206)

본 문서는 WhereIsIt 미니앱에서 **위치 탐색, 검색, 설정 화면의 메인 타이틀을 모두 `[아이콘] [제목]` 형식으로 일관되게 통일(1안: 브레드크럼 연동형)**하여, 시각적 규칙성과 하단 탭 바와의 연계성을 극대화한 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 개선 배경 및 사용자 피드백

1. **상황 및 사용자 피드백**:
   - "통일화 의미로 위치탐색, 검색, 설정 화면의 제목을 [아이콘] [제목] 으로 하면?"
   - 사용자가 제시한 1안(브레드크럼 연동형)으로 확정하여 진행.
2. **기존 상태 분석**:
   - **최상단 브랜드 헤더**: `[앱아이콘] 어디 뒀더라?`
   - **하단 탭 바**: `[Home] 홈`, `[Layers] 위치 탐색`, `[Search] 검색`, `[Settings] 설정`
   - **기존 각 화면 타이틀**:
     - 위치 탐색: 아이콘 없는 순수 텍스트 `전체 위치`
     - 검색: 아이콘 없는 순수 텍스트 `검색`
     - 설정: 아이콘이 뒤에 붙은 `설정 [Settings]`
   - 이로 인해 화면마다 타이틀 표기 규칙이 제각각이어서 시각적 통일감이 결여되어 있었습니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. 위치 탐색 화면 브레드크럼 뿌리 항목 통일 (`ExploreTab.tsx`)
- `Layers` 아이콘을 `lucide-react`에서 추가 임포트했습니다.
- 브레드크럼의 루트 항목인 `전체 위치`를 **`<Layers size={20} color="var(--toss-blue)" /> 위치 탐색`**으로 변경했습니다.
- 하위 경로(`거실`, `서랍장` 등)로 이동 시 `17px` 크기로 부드럽게 연계되며, 수직 공간을 낭비하지 않는 1안(브레드크럼 연동형) 구조를 완성했습니다.

### 2.2. 검색 화면 메인 타이틀 통일 (`SearchTab.tsx`)
- 기존 텍스트 형태의 `<h2 className="h2-title">검색</h2>`을 **`<h2 ...><Search size={20} color="var(--toss-blue)" /> 검색</h2>`**으로 변경했습니다.
- 20px 볼드 텍스트 앞에 20px 토스 블루 돋보기 아이콘을 배치하여 시각적 직관성을 대폭 개선했습니다.

### 2.3. 설정 화면 메인 타이틀 아이콘 선행 배치 (`SettingsTab.tsx`)
- 기존 `설정 [Settings]` 형태로 뒤에 있던 아이콘을 앞쪽으로 이동하여 **`<Settings size={20} color="var(--toss-blue)" /> 설정`**으로 정돈했습니다.

## 3. 화면별 변경 요약표

| 화면 | 기존 표기 | 변경 후 표기 (`[아이콘] [제목]`) | 규격 |
| :--- | :--- | :--- | :--- |
| **위치 탐색** | `전체 위치` | **`[Layers] 위치 탐색`** | 20px 토스 블루 아이콘 + 20px 볼드 |
| **검색** | `검색` | **`[Search] 검색`** | 20px 토스 블루 아이콘 + 20px 볼드 |
| **설정** | `설정 [Settings]` | **`[Settings] 설정`** | 20px 토스 블루 아이콘 + 20px 볼드 |
