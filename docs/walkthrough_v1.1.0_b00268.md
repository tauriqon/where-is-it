# 아 찾았다! (Where is it?) - v1.1.0 (b00268) 변경 내역 및 Walkthrough

**문서 생성일시**: 2026-11-21  
**대상 버전**: `v1.1.0 (b00268)`  
**작업 요약**: 최상단 이동(Scroll-to-Top) 플로팅 버튼 및 하단 네비게이션 메뉴 바를 상단 고정 헤더와 동일한 투명도 90% 및 최소 블러(`blur(4px)`) 수치로 통일 적용

## 1. 개선 배경 및 목적
- 상단 고정 헤더에 적용된 **투명도 90% (`rgba(255, 255, 255, 0.10)`)** 및 **최소 블러(`blur(4px)`)** 스타일을 **우측 하단 최상단 이동 버튼**과 **하단 네비게이션 메뉴 바**에도 동일한 치수(수치)로 일괄 적용하여 앱 전체 플로팅 바 및 컨트롤 UI의 심미적 통일감과 일관성을 완성.

---

## 2. 세부 변경 사항

### 1) 최상단 이동 플로팅 버튼 (`showScrollTop`)
- **파일**: `src/App.tsx`
- **배경색**: `rgba(255, 255, 255, 0.65)` ➔ `rgba(255, 255, 255, 0.10)` (**투명도 90%**, 불투명도 10%)
- **블러 필터**: `backdropFilter: blur(16px)` ➔ `backdropFilter: blur(4px)`
- **경계선 및 그림자**: `1px solid rgba(0, 0, 0, 0.04)`, `boxShadow: 0 4px 16px rgba(0, 0, 0, 0.10)`
- **효과**: 투명한 원형 글래스 버튼으로 전환되어 배경을 거의 가리지 않고 가볍게 떠 있으며, 상향 화살표 아이콘은 선명하게 유지.

### 2) 하단 네비게이션 메뉴 바 (`<nav>`)
- **파일**: `src/App.tsx`
- **배경색**: `rgba(255, 255, 255, 0.92)` ➔ `rgba(255, 255, 255, 0.10)` (**투명도 90%**, 불투명도 10%)
- **블러 필터**: `backdropFilter: blur(12px)` ➔ `backdropFilter: blur(4px)`
- **상단 경계선**: `1px solid var(--border-subtle)` ➔ `1px solid rgba(0, 0, 0, 0.04)`
- **효과**:
  - 화면 맨 아래까지 스크롤 시 하단 메뉴 바 아래로 콘텐츠가 90% 투명도로 맑고 시원하게 비치며 전체 화면이 더 넓어 보이는 효과.
  - 탭 아이콘 및 텍스트는 선명한 고대비 컬러를 유지하여 조작 편의성 보장.
