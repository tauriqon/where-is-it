## 1. 개선 배경 및 목적
- **입력 흐름과 시각적 맥락 일치**:
  - 기존에는 물건 사진 등록 영역이 '3단계 위치 지정'과 '수량' 아래, 즉 화면 중하단에 멀리 떨어져 있어 물건의 핵심 정보인 '이름'과 '사진'이 분리되어 있었습니다.
  - 사용자가 물건을 등록할 때 "무엇을 등록하는가 (이름 + 사진)"를 상단에서 한 번에 정의하고, 이어서 "어디에 보관하는가 (위치 3단계)", 그리고 세부 속성(수량, 유통기한, 태그, 메모)을 순차적으로 입력할 수 있도록 입력 흐름을 직관적으로 재정돈했습니다.
