## 1. 개선 배경 및 목적
- 스크롤 시 상단 헤더 아래를 지나는 콘텐츠가 더욱 맑고 선명하게 비쳐 보일 수 있도록 투명도를 90%(불투명도 10%)로 조정 요청 반영.

---

## 2. 세부 변경 사항

### 1) 상단 고정 헤더 투명도 90% 적용 (`renderStickyHeader`)
- **파일**: `src/components/SettingsTab.tsx`
- **배경색 설정**:
  - 기존: `rgba(255, 255, 255, 0.30)` (투명도 70%, 불투명도 30%)
  - 변경: `rgba(255, 255, 255, 0.10)` (투명도 90%, 불투명도 10%)
- **블러 필터 유지**: `backdropFilter: 'blur(16px)'`
- **하단 경계선 미세 조정**: `borderBottom: '1px solid rgba(0, 0, 0, 0.04)'`
- **효과**:
  - 화면을 스크롤할 때 밑으로 지나가는 카드와 글씨의 원래 색감과 윤곽이 90% 투명도로 아주 선명하고 시원하게 비침.
  - 16px의 블러 효과와 뒤로가기 버튼(`rgba(255, 255, 255, 0.72)`)의 독립 배경을 통해 상단 타이틀 및 뒤로가기 터치 버튼의 조작 가독성은 안정적으로 유지됨.
