## 🔍 배경 및 문제 해결 (Problem & Solution)

### 1. 바텀시트 내 물건 사진 크기 최적화 (50% 축소)
- **기존 문제**: 물건 상세 및 수정 화면에서 사진이 가로 100%에 `minHeight: 240px` (세로 모바일 사진의 경우 400px~500px 이상)로 표시되어, 바텀시트 오픈 시 화면 대부분을 사진이 가려 수납 위치, 수량, 유통기한 등의 핵심 정보를 보려면 과도하게 스크롤해야 했습니다.
- **개선 내용**: 
  - 사진의 최대 높이를 `maxHeight: 140px`로 제한하고 비율을 유지(`objectFit: 'contain'`)하면서 부드러운 배경 카드 내에 중앙 정렬하여 크기를 약 50% 축소하였습니다.
  - 상세 화면에서 사진을 탭하면 기존과 동일하게 전체 화면 사진 뷰어(`onZoomImage`)가 실행되므로 큰 사진 확인도 편리하게 지원합니다.
  - 등록된 사진이 없을 때의 플레이스홀더 박스 높이도 `140px` -> `80px`로 슬림화하였습니다.

### 2. 물건 사진 수정 안내 설명 및 변경 뱃지 추가
- **개선 내용**:
  - 라벨 하단에 안내 가이드 문구 추가:  
    `💡 사진을 누르면 다른 사진으로 변경하거나 새로 촬영할 수 있어요. (우측 ✕ 버튼으로 삭제)`
  - 미리보기 사진 하단 중앙에 직관적인 `[📷 사진 변경하기]` 알약형 뱃지를 배치하여 사진을 터치하면 바로 카메라 촬영 또는 앨범 선택 창이 열리도록 UX를 개선하였습니다.

### 3. 사진 삭제 시 미저장 변경사항 감지 누락 버그 해결
- **기존 버그**: `hasUnsavedChanges`에서 사진 변경 여부를 단순히 `!!editImageFile`(새 파일이 선택되었는가)로만 체크하고 있었습니다. 그 결과 사용자가 기존에 등록되어 있던 사진을 `✕` 버튼으로 삭제하여 `editImagePreview`가 `null`이 되었을 때, `editImageFile` 역시 `null`이므로 변경사항이 없다고 잘못 판단하여 바텀시트 `✕` 클릭 시 아무런 경고 없이 그냥 닫히는 현상이 발생했습니다.
- **수정 내용**: 
  - 원래 물건의 사진 URL(`origImageUrl`)과 현재 편집 화면의 미리보기 상태(`currentImageUrl`)를 상호 비교하는 로직을 추가하였습니다:  
    `const hasImageChanged = !!editImageFile || (currentImageUrl !== origImageUrl);`
  - 이제 사진을 삭제하거나 다른 사진으로 변경한 경우 모두 `hasUnsavedChanges`가 `true`로 인식되어, 바텀시트 `✕`, 뒤로가기 `<`, 하단 `[취소]` 시  
    `"수정 중인 내용이 있습니다. 변경사항을 저장하지 않고 나가시겠습니까?"`  
    확인 팝업이 확실하게 동작합니다.
