# 🚨 WhereIsIt 유통기한 뱃지 시각 강조 이모지(🚨, ⚠️, ⏰) 및 '까지' 표현 개선 (v00189)

본 문서는 WhereIsIt 미니앱에서 유통기한 안내 뱃지의 시각적 긴급도 인지성을 극대화하기 위해 **경고 및 알림 이모지(`🚨`, `⚠️`, `⏰`)**를 추가하고, 다소 딱딱하거나 부정적 뉘앙스를 주는 **'만료'라는 단어를 친근하고 명확한 '까지'로 변경**(`⚠️ 오늘까지`, `⏰ 내일까지`)한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. [v00189] 주요 변경 및 개선 사항

### 1.1. 직관적인 경고 이모지(`🚨`, `⚠️`, `⏰`) 도입 및 '까지' 표현 적용
유통기한 상태에 따른 시각적 경각심을 높이고, 직관성을 한 차원 끌어올렸습니다.

| 유통기한 상태 | 기존 표기 (v00188) | **개편 표기 (v00189)** | 배경 및 텍스트 스타일 |
| :--- | :--- | :--- | :--- |
| **기한 지남** (`dday < 0`) | `3일 지남` | **`🚨 3일 지남`** | 빨간색 배경(`var(--accent-red-light)`) + 빨간 텍스트 |
| **당일** (`dday === 0`) | `오늘 만료` | **`⚠️ 오늘까지`** | 경고 빨간색 + 붉은색 테두리 |
| **내일** (`dday === 1`) | `내일 만료` | **`⏰ 내일까지`** | 선명한 오렌지 배경 + 오렌지 텍스트 |
| **임박** (`1 < dday <= 알림일수`) | `3일 남음` | **`3일 남음`** | 부드러운 주황 배경 + 주황 텍스트 |
| **여유** (`dday > 알림일수`) | `30일 남음` | **`30일 남음`** | 차분한 그레이 배경 + 보조 텍스트 |

---

### 1.2. 홈 탭 유통기한 도래 바텀시트 안내 문구 개선
- **`src/components/HomeTab.tsx`**:
  - 기존: `subtitle="만료되었거나 유통기한이 임박한 순서대로 정렬되어 있습니다."`
  - 개선: `subtitle="기한이 지났거나 임박한 순서대로 정렬되어 있습니다."`
  - '만료' 대신 일관성 있게 '기한이 지났거나'로 정제하여 자연스러운 문장 전달력 확보.

---

### 1.3. 공통 유틸리티 기반 전 화면 자동 동기화
`src/utils/expiration.ts`의 표준 뱃지 생성 함수 `getExpirationBadgeInfo()`를 통해 홈 탭, 탐색 탭(Level 4 물건 목록 및 상세 바텀시트), 검색 탭(검색 결과 및 상세 바텀시트) 모두에 새로운 이모지와 '까지' 라벨이 즉시 일괄 적용되었습니다.
