# 📐 WhereIsIt 앱 재실행 시 항상 홈 화면 시작 및 등록 미완료 시 앱 종료/이탈 방어 경고 구축 (v00218)

본 문서는 WhereIsIt 미니앱에서 **앱을 껐다가 다시 실행할 때 항상 '홈(Home)' 탭에서 새롭고 일관되게 시작하도록 진입 로직을 개편하고, 물건 등록 화면에서 입력 중 앱을 종료(뒤로가기, 탭 닫기 등)하려 할 때 데이터 유실을 방지하는 다중 종료/이탈 방어 경고 시스템을 구축한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 개선 배경 및 사용자 피드백

1. **사용자 요청 사항 (Tauriqon님)**:
   - "앱 재실행 시 항상 홈 화면으로 시작하자."
   - "그런데 등록화면을 완료하지 않은 상태에서 종료시 경고는 띄워야 겠지?"

2. **문제점 및 사용자 경험 분석**:
   - **기존 동작**: `localStorage`에 마지막 활성 탭(`wii_active_tab`)을 영구 저장하고 있어, 며칠 뒤 앱을 실행해도 직전에 보던 '등록'이나 '설정' 화면으로 바로 열려 사용자의 맥락이 단절되고 불필요하게 홈 탭을 다시 눌러야 하는 불편함이 있었습니다.
   - **종료 방어 필요성**: 만약 물건 등록을 위해 여러 정보를 입력하던 도중 실수로 안드로이드/토스 뒤로가기 버튼을 누르거나 브라우저 창을 닫아버리면 작성 중이던 소중한 데이터가 날아갈 수 있으므로 확실한 이탈 확인 경고가 필수적이었습니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. 앱 재실행(Launch) 시 항상 '홈 화면'으로 초기화 (`src/App.tsx`)
- **초기 상태 기본값 고정**:
  ```tsx
  // 5대 탭 통합 정의 (앱 시작 시 항상 'home' 화면으로 초기화)
  const [activeTab, setActiveTab] = useState<'home' | 'explore' | 'add' | 'search' | 'settings'>('home');

  // 설정 탭 내부 서브페이지도 기본값 'main'으로 초기화
  const [settingsSubPage, setSettingsSubPage] = useState<'main' | ...>('main');
  ```
- **기존 로컬스토리지 탭 영구 보존 로직 제거**:
  - `handleNavigateTab` 및 `handleSettingsSubPageChange`에서 `localStorage.setItem('wii_active_tab')` 호출을 완전히 제거.
  - 앱 마운트 시 `localStorage.removeItem('wii_active_tab')`, `localStorage.removeItem('wii_settings_subpage')`를 실행하여 과거 버전의 잔존 캐시를 소거하고 항상 '홈' 탭에서 진입하도록 보장.

### 2.2. 등록 미완료 시 다중 종료/이탈 방어 경고 구축 (`src/components/AddTab.tsx`)
1. **뒤로가기(Back) 버튼으로 앱 종료/이탈 시도 시**:
   - 사용자가 등록 화면에서 안드로이드/토스 뒤로가기를 누르면 `registerBackHandler`가 가로채어:
     ```
     물건 등록을 취소하시겠습니까?
     작성 중인 내용이 초기화됩니다.
     ```
   - **[취소] 선택**: 화면 이동과 종료를 차단하고 등록 폼에 그대로 머무릅니다.
   - **[확인] 선택**: 입력 데이터와 드래프트를 비우고 안전하게 홈 화면으로 이동하며, 홈 화면에서 한 번 더 뒤로가기를 눌러야 최종 앱 종료 팝업(`isExitModalOpen`)이 노출됩니다.
2. **브라우저 닫기/새로고침(`beforeunload`) 시**:
   - 물건 이름, 사진, 메모, 위치 등 작성 중인 내용이 있을 때(`checkHasContent()`) `window.beforeunload` 이벤트를 리스닝하여 브라우저 수준의 이탈 확인 팝업을 띄우고 데이터가 임의로 유실되지 않도록 방어합니다.
3. **하단 탭 전환 시 (v00217 연계)**:
   - 등록 도중 다른 탭(홈, 탐색, 검색 등)을 탭해도 동일하게 확인창이 동작하여 오작동을 철저히 차단합니다.

## 3. 변경 파일 목록

1. `src/App.tsx`:
   - `activeTab` 기본값을 'home'으로 설정
   - `localStorage` 탭 영구 저장 로직 제거 및 마운트 시 잔존 키 정리
   - `forceReload` 및 `ErrorBoundary` 정리 로직 보강
2. `src/components/AddTab.tsx`:
   - `beforeunload` 이벤트 리스너 추가하여 창 닫기/새로고침 시 데이터 유실 방어
3. `src/version.ts` & `.env`:
   - 앱 버전을 `v00218`으로 업데이트

## 4. 검증 결과

1. **빌드 검증**:
   - `npm run build` 결과 Vite 및 앱인토스 패키징(`family-inventory.ait`) 0 에러로 빌드 완료.
2. **동작 검증**:
   - 앱을 닫고 다시 열면 이전 탭과 상관없이 항상 친숙하고 안정적인 **'홈' 탭**에서 시작됨.
   - 등록 화면에서 작성을 진행한 후 뒤로가기 누를 시 확인창이 먼저 뜨고, 창 닫기 시에도 이탈 방어 경고가 정상 작동함.
