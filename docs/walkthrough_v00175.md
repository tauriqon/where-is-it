## 1. [v00175] 구현된 두 가지 디자인 상세

### 1.1. [1안] 토스 블루 포인트 캡슐 바
- **컨셉**: 정돈된 토스 오리지널 룩앤필 (클래식 프리미엄 미니멀리즘)
- **비주얼 스펙**:
  - 모서리: `borderRadius: 24px` 완전한 캡슐 라운딩
  - 배경: 순백색(`#ffffff`) + 은은한 토스 블루 틴트 테두리 (`1.5px solid rgba(49, 130, 246, 0.25)`)
  - 그림자: 입체적인 소프트 플로팅 섀도우 (`0 4px 16px rgba(49, 130, 246, 0.08)`)
  - 좌측: 볼드 토스 블루 돋보기 아이콘 (`#3182f6`, `strokeWidth: 2.5`)
  - 텍스트: 선명하고 읽기 편한 고정 문구 (`"어떤 물건을 찾고 계신가요?"`)
  - 우측 액션 배지: 토스 블루 `[검색]` 캡슐 버튼

### 1.2. [3안] 실시간 롤링 키워드 캡슐 바
- **컨셉**: 생동감 넘치는 동적 검색 제안 (인터랙티브 모던 UX)
- **비주얼 스펙**:
  - 모서리: `borderRadius: 24px` 캡슐 라운딩
  - 배경: 미세 파스텔 그라데이션 (`linear-gradient(135deg, #ffffff 0%, #f8faff 100%)`) + 인디고/바이올렛 틴트 보더 (`rgba(99, 102, 241, 0.25)`)
  - 그림자: 소프트 바이올렛 플로팅 섀도우 (`0 4px 16px rgba(99, 102, 241, 0.08)`)
  - 좌측: 인디고 돋보기 아이콘 (`#6366f1`, `strokeWidth: 2.5`)
  - 텍스트 롤링: 2.5초 간격으로 부드러운 페이드/슬라이드 전환 애니메이션:
    1. `"손톱깎이 어디 뒀더라?"`
    2. `"여권 어디 뒀더라?"`
    3. `"상비약 어디 뒀더라?"`
    4. `"건전지 어디 뒀더라?"`
    5. `"어떤 물건을 찾고 계신가요?"`
  - 우측 액션 배지: 인디고 `[찾기]` 캡슐 버튼
