# 📱 '아 찾았다 · 내 물건 찾기' 토스 콘솔 앱 정보 상세설명 (v1.1.0 기준)

## 1. [추천] 표준 완성형 (상세 및 기능 강조형)

[아 찾았다 · 내 물건 찾기]는 집안 물건의 위치를 스마트하게 기록하고 3초 만에 찾아내는 가족 & 개인 수납 인벤토리 서비스입니다.

"여보, 건전지 어디 있어?", "내 여권 어디 뒀더라?"
더 이상 어디 뒀는지 기억나지 않아 헤매지 마세요! 일상 소지품부터 계절 용품, 상비약, 귀중품까지 온 가족이 똑똑하게 관리할 수 있습니다.

1. 온 가족이 함께 확인하는 '가족 공유 기능'
- 부부, 자녀, 룸메이트와 보관소를 함께 공유하고 물건 위치를 실시간으로 확인하세요.
- '워크스페이스 전환'으로 내 개인 보관소는 100% 안전하게 보호되며, [가족 보관소 ↔ 내 보관소]를 1초 만에 원터치 전환할 수 있습니다.
- 1회용 안심 초대 티켓으로 소유권 탈취 걱정 없이 안전하게 가족을 초대하세요.

2. 사진만 찍으면 끝나는 'AI 비전 스마트 인식'
- 물건 사진을 촬영하거나 앨범에서 올리면, AI가 물건 이름과 관련 카테고리 태그를 자동으로 분석해 채워줍니다.
- 복잡한 텍스트 타이핑 없이 사진 한 장으로 손쉽게 등록하세요.

3. 3단계 스마트 공간 탐색 & 연속 등록 편의성
- 공간(예: 거실, 서재) ➔ 수납처(예: 서랍장, 책꽂이) ➔ 세부 칸으로 이어지는 직관적인 구조로 각 위치의 물건과 사진을 한눈에 확인합니다.
- 이전에 등록한 위치를 자동으로 기억하여, 같은 서랍이나 선반에 여러 물건을 연속으로 등록할 때 매번 위치를 다시 고를 필요가 없습니다.

4. 초성까지 지원하는 3초 초고속 검색
- 이름이나 초성(예: 'ㄱㅇ' ➔ 가위, 'ㅊㅈㄱ' ➔ 충전기), 해시태그를 입력하면 물건이 보관된 정확한 위치(공간/수납처/칸)와 메모를 즉시 찾아냅니다.

5. 기기 변경 걱정 없는 '영구 복구 코드' & 데이터 안전망
- 스마트폰을 바꾸거나 앱을 재설치해도 나만의 6자리 마스터 복구 코드로 1초 만에 모든 데이터를 완벽하게 복원합니다.
- 실수로 물건을 잘못 지워도 5초간 '실행 취소(Undo)'로 즉시 되돌릴 수 있습니다.

6. 상비약·식료품 유통기한 D-Day 스마트 관리
- 유통기한 알림일과 D-Day 뱃지를 통해 버려지는 물건 없이 알뜰하게 소비 주기를 관리할 수 있습니다.

## 2. [옵션] 컴팩트 요약형 (간결형)

[아 찾았다 · 내 물건 찾기]는 집안 물건의 보관 위치를 스마트하게 기록하고 3초 만에 찾아내는 수납 인벤토리 서비스입니다.

어디 뒀는지 기억나지 않아 헤매던 일상 소지품부터 계절 용품, 상비약까지 온 가족이 똑똑하게 관리해 보세요!

1. 안심 가족 공유 기능: 부부·가족과 보관소를 함께 공유하고, [가족 보관소 ↔ 개인 보관소]를 1초 만에 안전하게 전환합니다.
2. AI 비전 자동 인식: 사진만 찍으면 AI가 물건 이름과 카테고리 태그를 자동으로 분석해 손쉽게 등록합니다.
3. 3단계 공간 탐색 & 연속 등록: 공간 ➔ 수납처 ➔ 세부 칸 계층 구조와 마지막 위치 자동 기억으로 대량 정리도 빠르게 끝냅니다.
4. 초성까지 지원하는 3초 검색: 'ㄱㅇ'만 쳐도 '가위'의 정확한 보관 위치와 메모를 즉시 확인합니다.
5. 6자리 영구 복구 코드: 스마트폰을 바꾸거나 재설치해도 복구 코드로 1초 만에 내 데이터를 그대로 복원합니다.
6. 유통기한 D-Day & 실행 취소: 상비약 유통기한 D-Day 관리와 실수 삭제 방지 5초 실행 취소(Undo)를 지원합니다.
