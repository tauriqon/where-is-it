# 🧭 WhereIsIt 긴 위치 이름 전체 표시: 가로 스크롤 브레드크럼 & 2줄 카드 줄바꿈 (v00187)

본 문서는 WhereIsIt 미니앱에서 공간, 수납처, 세부위치의 이름이 길어질 때 `...`로 말줄임 잘림 현상이 발생하던 문제를 해결하기 위해, **방안 A(가로 스크롤 브레드크럼 + 카드 텍스트 2줄 자연 줄바꿈)**를 적용하여 긴 이름을 100% 온전하게 확인하고 조작할 수 있도록 개선한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. [v00187] 주요 변경 및 개선 사항

### 1.1. 상단 브레드크럼: 토스/애플 스타일 가로 스크롤 칩 네비게이션
기존에는 너비 제한(`maxWidth: 130px`)과 말줄임(`text-overflow: ellipsis`)으로 인해 긴 공간/수납처 이름이 잘려서 표시되었습니다.

- **말줄임 해제 및 100% 풀네임 노출**:
  - `maxWidth` 및 `ellipsis` 속성을 제거하고, 모든 경로 항목에 `flexShrink: 0`, `whiteSpace: 'nowrap'` 적용
  - 아무리 긴 이름(예: `안방 및 드레스룸`, `3단 시스템 붙박이장`, `속옷 및 양말 보관함`)도 글자 하나 잘림 없이 온전히 표시
- **부드러운 가로 스크롤(Horizontal Swipe) 지원**:
  - `overflowX: 'auto'`, `-webkit-overflow-scrolling: touch` 및 스크롤바 숨김(`no-scrollbar`) 처리로 깔끔한 스와이프 인터랙션 완성
- **하위 단계 진입 시 자동 스크롤(Auto-scroll) 연동**:
  - 사용자가 다음 단계(공간 ➔ 수납처 ➔ 세부위치)로 들어갈 때마다, `useEffect`와 `ref`를 통해 **가장 최근에 선택된 활성 위치(우측 끝)로 화면이 부드럽게 자동 스크롤**되어 진입한 위치를 즉시 확인 가능

---

### 1.2. 공간 / 수납처 / 세부위치 카드: 자동 2줄 줄바꿈(Multi-line) 적용
카드의 이름 텍스트 영역에 고정되어 있던 1줄 강제 제한(`whiteSpace: 'nowrap'`)을 해제했습니다.

- **`wordBreak: 'keep-all'` & `lineHeight: '1.35'` 적용**:
  - 이름이 긴 경우 카드의 높이가 자연스럽게 늘어나며 단어 단위로 2줄로 감싸져 표시
  - 카드의 우측 정보(보관 물건 개수, 화살표)와 겹치지 않고 온전한 이름을 한눈에 확인 가능
- **대상 카드 목록**:
  - 1단계: 공간 카드 (`space.name`)
  - 2단계: 수납처 카드 (`storage.name`)
  - 3단계: 세부위치 카드 (`section.name`)
