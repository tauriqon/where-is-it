## 1. [v00171] 홈 화면 '최근 활동 물건' 단일 섹션 통합

### 1.1. 배경 및 개선 목표
- 기존 홈 화면에서는 **[최근 등록한 물건]**과 **[최근 수정한 물건]** 섹션이 물리적으로 분리되어 있어 세로 스크롤 영역을 과도하게 차지하고 사용자 시선이 분산되는 문제가 있었습니다.
- 이를 하나의 **[최근 활동 물건]** 섹션으로 통합하여 스크롤 동선을 획기적으로 줄이고, 최근에 등록하거나 수정한 물건을 일목요연하게 파악할 수 있도록 개선했습니다.

### 1.2. 주요 기술 구현
- **파일**: `src/components/HomeTab.tsx`
- **최신 활동순 정렬 (`recentActivityItems`)**:
  - `created_at`(등록일시)과 `updated_at`(수정일시) 중 더 최신 시점을 `latestTime`으로 계산.
  - Supabase/PostgreSQL의 기본 타임스탬프 트리거로 인해 등록 직후 동시에 기록되는 미세 오차(2초 이내)를 제외하고, 실제 이후 수정된 경우에만 `isUpdated = true`로 정확히 판별.
  - 등록과 수정 구분 없이 가장 최근 활동이 일어난 상위 **최대 4개** 아이템을 최신순으로 추출.
- **시각적 상태 배지 (`신규` / `수정됨`)**:
  - `신규`: 토스 블루 포인트 배경(`var(--toss-blue-light)`)과 블루 텍스트(`var(--toss-blue)`)로 산뜻하게 강조.
  - `수정됨`: 차분한 서브 배경(`var(--bg-input)`)과 세컨더리 텍스트(`var(--text-secondary)`)로 시각적 위계 부여.
- **활동 일자 및 직관적 내비게이션**:
  - 물건 카드 우측에 최신 활동 날짜와 우측 화살표(`ChevronRight`)를 배치하여 클릭 시 즉시 해당 물건의 상세 위치 탐색 탭으로 원활하게 이동.

## 2. [v00170] 프로젝트 규칙(`AGENTS.md`) 및 환경 안정성 강화

### 2.1. 동기 실행 원칙 (Synchronous Shell Execution)
- 비동기 백그라운드 태스크로 인한 프로세스 누수 및 UI 스피너 잔여 문제를 방지하기 위해 모든 셸 명령어에 충분한 동기 대기 시간(`WaitMsBeforeAsync: 10000ms`)을 부여.

### 2.2. 백그라운드 태스크 정리 의무화 (Zero Lingering Tasks)
- 매 작업 종료 시 백그라운드 태스크 리스트가 100% 비어 있는지(`0 tasks running`) 반드시 검증하고 잔여 태스크 발생 시 즉각 kill/정리하도록 규칙을 영구 명시.

### 2.3. Git 명령어 샌드박스 바이패스 (`BypassSandbox: true`)
- macOS 샌드박스 환경에서 `~/.gitignore_global` 등 전역 설정 접근 시 발생할 수 있는 락업을 방지하고 즉각적인 동기 완료를 보장하기 위해 Git 명령어에 `BypassSandbox: true` 적용.

## 3. [v00169] 전면 광고(Interstitial Ad) 노출 시점 UX 매끄러움 보완

### 3.1. 배경 및 토스 심사 정책 대응
- 토스 미니앱 운영 정책(광고 어뷰징 방지 및 비게임 미니앱 전수 점검 가이드)에 따라, 30개 초과 무료 보관 시 송출되는 전면 광고의 돌발 팝업을 방지하고 매끄러운 사전 안내 토스트 및 트랜지션을 적용.

### 3.2. 주요 기술 구현
- **토스 스타일 경량 플로팅 토스트 시스템 신설** (`src/utils/toast.ts`):
  - 리액트 라이프사이클이나 바텀시트/네비게이션에 간섭 없는 순수 DOM 기반 플로팅 토스트 컴포넌트(`showToast`) 구현.
  - 노치 Safe Area(`env(safe-area-inset-bottom)`)와 하단 탭 바를 감안한 부드러운 스케일/페이드 애니메이션 적용.
- **전면 광고 1초 사전 안내 토스트** (`src/services/ads.ts`):
  - 전면 광고 송출 조건 충족 시, 화면을 즉시 가로막지 않고 `💡 30개 이상 보관 중: 잠시 후 안내 광고가 표시됩니다.` 토스트를 1초간 먼저 노출하여 사용자에게 충분한 유예 시간 제공.
- **데이터 저장 완료 피드백 우선 보장** (`src/contexts/DataContext.tsx`):
  - 물건 등록/수정 완료 직후 React 상태(`setItems`)가 먼저 커밋되어 '저장 완료' 피드백이 확실히 체감된 후 700ms 딜레이를 두고 광고가 트리거되도록 분리.
