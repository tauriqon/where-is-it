## 2. 세부 변경 사항

### 1) 상단 고정 헤더 투명도 70% 적용 (`renderStickyHeader`)
- **파일**: `src/components/SettingsTab.tsx`
- **배경색 설정**:
  - 기존: `rgba(255, 255, 255, 0.55)` (투명도 45%, 불투명도 55%)
  - 변경: `rgba(255, 255, 255, 0.30)` (투명도 70%, 불투명도 30%)
- **블러 필터 유지**: `backdropFilter: 'blur(16px)'`
- **하단 경계선 미세 조정**: `borderBottom: '1px solid rgba(0, 0, 0, 0.05)'` (배경이 맑아짐에 따라 경계선이 과하게 도드라지지 않도록 자연스럽게 매칭)
- **효과**:
  - 화면을 스크롤하여 위로 올릴 때, 상단 고정 헤더 아래를 통과하는 카드 형태, 아이콘, 텍스트의 실루엣이 70% 투명도로 선명하고 부드럽게 비침.
  - 16px의 블러 효과와 뒤로가기 버튼(`rgba(255, 255, 255, 0.72)`)의 독립 배경 덕분에 상단 제목 및 버튼 조작 가독성은 완벽히 유지됨.
