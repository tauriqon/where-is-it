# ⏰ WhereIsIt 유통기한 정보 표현 한글 자연어(1안) 전면 개편 (v00188)

본 문서는 WhereIsIt 미니앱에서 기존의 군대/수능식 기호 표기(`D-3`, `만료 (D+3)`, `D-Day`)로 인해 직관적인 인지성이 떨어지던 유통기한 정보를, **방안 1(한글 자연어 기반: `N일 지남`, `오늘 만료`, `내일 만료`, `N일 남음`)**로 전면 개편하여 남녀노소 누구나 0.1초 만에 상태를 파악할 수 있도록 개선한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. [v00188] 주요 변경 및 개선 사항

### 1.1. 직관적인 한글 자연어 표기 규칙 도입
기호(`D-`, `+`)의 부호 연산으로 인한 인지 부하를 없애고, 토스 및 마켓컬리 스타일의 선명한 한글로 상태를 즉시 알 수 있도록 개선했습니다.

| 유통기한 상태 | 기존 표기 (v00187) | **개편 표기 (v00188)** | 배경 및 텍스트 스타일 |
| :--- | :--- | :--- | :--- |
| **기한 지남** (`dday < 0`) | `만료 (D+3)` | **`3일 지남`** | 빨간색 배경(`var(--accent-red-light)`) + 빨간 텍스트 |
| **당일 만료** (`dday === 0`) | `D-Day` | **`오늘 만료`** | 경고 빨간색 + 붉은색 테두리 |
| **내일 만료** (`dday === 1`) | `D-1` | **`내일 만료`** | 선명한 오렌지 배경 + 오렌지 텍스트 |
| **임박** (`1 < dday <= 알림일수`) | `D-3` | **`3일 남음`** | 부드러운 주황 배경 + 주황 텍스트 |
| **여유** (`dday > 알림일수`) | `D-30` | **`30일 남음`** | 차분한 그레이 배경 + 보조 텍스트 |

---

### 1.2. 공통 유틸리티 모듈 구축 (`src/utils/expiration.ts`)
화면마다 파편화되어 계산되던 유통기한 로직을 단일 유틸리티 함수로 표준화하여 일관된 디자인과 유지보수성을 확보했습니다.

- **`getDDay(expirationDate)`**: 자정 기준 날짜 차이(일수) 계산
- **`getExpirationBadgeInfo(expirationDate, customNotifyDays)`**:
  - 상태에 따른 한글 라벨(`label`), 텍스트 색상(`color`), 배경색(`bg`), 테두리(`border`), 만료 여부(`isExpired`), 임박 여부(`isImminent`)를 한 번에 반환

---

### 1.3. 전 화면(3대 탭) 일괄 적용
1. **홈 탭 (`HomeTab.tsx`)**:
   - 유통기한 도래 물건 카드 뱃지 (`3일 지남`, `오늘 만료`, `내일 만료`, `N일 남음`)
   - 유통기한 도래 전체보기 바텀시트 목록
2. **탐색 탭 (`ExploreTab.tsx`)**:
   - Level 4 보관 물건 카드 뱃지
   - 물건 상세정보 바텀시트 유통기한 뱃지
3. **검색 탭 (`SearchTab.tsx`)**:
   - 검색 결과 물건 카드 뱃지
   - 물건 상세정보 바텀시트 유통기한 뱃지
