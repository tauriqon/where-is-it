# Walkthrough v1.1.0-b00259: 공유 메시지 스마트 코드 자동 추출 및 입력 편의성 개선

## 1. 개요 및 사용자 질문
- **사용자 질문 (Tauriqon님)**:
  > "이 메시지 에서 공유코드만 복사가 가능한가?"
- **질문 배경 및 UX 개선 방향**:
  - 카카오톡이나 문자 메시지 등에서 말풍선을 길게 눌러 전체 복사할 경우, 안내 문구와 함께 전체 3줄이 클립보드에 들어가는 경우가 많습니다.
  - 사용자가 공유 코드를 입력할 때 직접 앞뒤 텍스트를 지우는 번거로움을 완전히 없애기 위해, **전체 메시지를 통째로 복사해 붙여넣어도 공유 코드(`wii-xxxxxx`)만 스마트하게 자동 추출**되는 기능을 구현하였습니다.
  - 또한, 앱 내 [복사] 버튼을 터치하면 안내문구 없이 오직 순수 코드(`wii-xxxxxx`)만 복사됩니다.

---

## 2. 주요 변경 사항 및 동작 원리

### 2.1. 붙여넣기 시 스마트 코드 자동 추출 (Smart Auto-Extraction)
- **가족 동기화 코드 입력창 (`syncCodeInput`)**:
  - 전체 메시지(`[아 찾았다!] ... 코드 : wii-xxxxxx`)를 통째로 복사하여 붙여넣더라도, `onChange` 및 신청 핸들러에서 정규식(`/wii-[a-z0-9]+/i`)을 통해 자동으로 `wii-xxxxxx` 코드만 추출하여 입력창에 채워집니다.
- **보관소 복구/기기변경 코드 입력창 (`recoveryInput`)**:
  - 복구 안내 메시지나 전체 텍스트를 복사해 붙여넣어도 `wii-xxxxxx` 형태 또는 6자리 숫자 코드를 자동으로 인식하고 추출하여 즉시 입력됩니다.
- **소문자 정규화**:
  - 대소문자 구분 없이 입력하거나 복사해도 자동으로 표준 소문자로 변환되어 오류 없이 처리됩니다.

### 2.2. 공유 및 복사 방식 안내
1. **앱 내 [복사] 버튼 사용 시**: 안내 문구 없이 `wii-xxxxxx` 코드만 순수하게 클립보드에 복사됩니다.
2. **카카오톡/문자에서 메시지를 받았을 때**:
   - `wii-xxxxxx` 부분을 더블 탭(또는 길게 누름)하여 해당 코드만 선택 복사할 수 있습니다.
   - **말풍선 전체를 복사하여 앱 입력창에 그대로 [붙여넣기]하더라도 앱이 자동으로 코드만 쏙 뽑아내어 입력하므로 아무런 문제가 없습니다.**
