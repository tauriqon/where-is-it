## 1. 개선 배경 및 목적
- Tauriqon님의 요청: *"여기서 저장이 끝나면 Top로 이동하는 것이 좋겠다"*
- 연속 등록 시 물건 저장 후 화면에 머무르면서 위치 3단계를 유지하지만, 저장 버튼이 화면 하단에 위치해 있어 저장 직후 스크롤 위치가 하단에 머무를 경우 사용자가 다음 물건 사진을 찍거나 이름을 확인하기 위해 손가락으로 화면을 일일이 위로 올려야 하는 번거로움이 있었습니다.
- 물건 저장 성공 즉시 화면 뷰포트를 최상단(Top)으로 부드럽게 자동 스크롤시켜, 다음 물건의 이름 및 사진 등록 폼을 즉시 한눈에 확인하고 바로 촬영/입력할 수 있도록 UX를 최적화했습니다.

---

## 2. 세부 변경 사항 (`src/components/AddTab.tsx`)

### 1) `scrollToTop` 전용 헬퍼 함수 구현
- **포커스 해제(`blur`)**: 모바일 웹 브라우저(iOS Safari / Android Chrome / Toss WebView)에서 저장 버튼에 포커스가 유지되어 스크롤이 하단으로 되돌아가는 현상을 방지하기 위해 `document.activeElement.blur()` 실행.
- **다중 뷰포트 스크롤 타깃 지원**:
  - `main.scrollable` (앱 내 메인 스크롤 컨테이너)
  - `window` 및 `document.documentElement`, `document.body` 전체 연동.
- **다단계 타이밍 보장**:
  - 즉각 호출 + `requestAnimationFrame` + React 상태 업데이트(`isUploading` 해제 등) 후 80ms/100ms/200ms 지연 호출로 렌더링 후 스크롤 취소 현상을 완벽 방지.

### 2) 저장 완료(`handleSubmit`) 흐름 연동
- 물건 저장 성공 및 폼 초기화 직후 `scrollToTop()`을 트리거하여 뷰포트가 폼 최상단(물건 이름 및 사진 등록 섹션)으로 매끄럽게 이동.
- 토스트 알림(`🎉 "[물건명]" 등록 완료! 같은 위치에 다음 물건을 바로 등록할 수 있어요.`)과 함께 상단 화면에서 다음 물건 등록을 즉각 이어갈 수 있도록 구성.
