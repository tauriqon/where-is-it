# 📷 WhereIsIt 보관 위치 사진 미등록 시 직관적 안내 플레이스홀더 제공 (v00199)

본 문서는 WhereIsIt 미니앱에서 **기본 데이터로 생성되었거나 사진 없이 등록된 수납처/세부위치에 물건이 보관되어 있을 때, 물건 상세 화면에서 보관 위치 사진 영역이 완전히 숨겨져 사진 누락이나 오류로 오인되던 현상을 해결하고 "등록된 보관 위치 사진이 없습니다." 안내 배지를 명확하게 표시하도록 개선한 내역**을 정리한 워크스루(Walkthrough)입니다.

---

## 1. 개선 배경 및 사용자 피드백

1. **상황 및 현상**:
   - 사용자가 새로운 물건(예: "청바지")을 등록한 후 상세 팝업을 열었을 때, 물건 사진은 정상적으로 보이지만 아래의 보관 위치(`안방 > 옷장 > 옷걸이 칸`)에 수납처 사진 썸네일이 전혀 노출되지 않았습니다.
2. **원인 분석**:
   - 사용자의 예리한 분석대로, 앱 초기 진입 시 기본 생성된 2단계(수납처: `옷장`) 및 3단계(세부위치: `옷걸이 칸`)는 대표 아이콘만 설정되어 있고 실제 촬영된 사진(`image_url`)은 비어 있는 상태입니다.
   - 또한 사용자가 직접 새로운 수납처나 세부위치를 생성할 때도 사진 촬영을 건너뛸 수 있습니다(Optional).
   - 기존 코드에서는 `(hasSectionImage || hasStorageImage)` 조건문으로 둘 중 하나라도 사진이 있을 때만 사진 영역을 렌더링하고, 둘 다 사진이 없으면 영역 전체를 숨기도록 되어 있었습니다.
   - 이로 인해 사용자는 "수납처 사진이 왜 안 보이지? 저장이 안 되었거나 시스템 오류인가?"라고 느낄 수 있었습니다.

---

## 2. 주요 해결 및 변경 내역

### 2.1. 보관 위치 사진 미등록 시 전용 안내 배지 추가
- 보관 위치에 등록된 사진이 전혀 없을 때(`!hasStorageImage && !hasSectionImage`), 보관 위치 경로 바로 아래에 은은한 점선 테두리와 카메라 아이콘이 포함된 친절한 안내 배지를 표시하도록 개선했습니다:
  ```tsx
  <div style={{
    display: 'flex',
    alignItems: 'center',
    gap: '6px',
    marginTop: '10px',
    padding: '9px 12px',
    borderRadius: '8px',
    background: 'rgba(0, 0, 0, 0.025)',
    border: '1px dashed var(--border-medium)',
    color: 'var(--text-tertiary)',
    fontSize: '12.5px'
  }}>
    <Camera size={13} style={{ opacity: 0.7 }} />
    <span>등록된 보관 위치 사진이 없습니다.</span>
  </div>
  ```

### 2.2. 전 화면 상세 팝업 일관 적용
- `src/components/ItemDetailBottomSheet.tsx` (홈 탭 및 전역 물건 상세 바텀시트)
- `src/components/SearchTab.tsx` (검색 탭 물건 상세 바텀시트)
- `src/components/ExploreTab.tsx` (탐색 탭 물건 상세 바텀시트)
- 모든 뷰에서 동일한 UI 규칙을 적용하여, 사진이 있는 수납처는 종전처럼 고화질 썸네일(클릭 시 확대)을 시원하게 제공하고, 사진이 없는 위치는 깔끔한 안내를 띄워 상태를 명확히 인지할 수 있도록 했습니다.
