# 📦 WhereIsIt 홈 화면 컴팩트 대시보드 상하 간격 최적화 (v00192)

본 문서는 WhereIsIt 미니앱의 홈 탭에서 대시보드 컴포넌트 간의 불필요한 빈 여백을 줄여, 앱 진입 시 스크롤을 거의 내리지 않고도 **[보관 통계] ➔ [퀵 서치 바] ➔ [유통기한 도래 물건] ➔ [최근 활동 물건]**이 한눈에 시원하고 쾌적하게 쏙 들어오도록 **홈 화면 상하 간격을 컴팩트하게 최적화**한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. [v00192] 주요 변경 및 개선 사항

### 1.1. 상하 간격 컴팩트 최적화 상세 내역 (1안 적용)

| 컴포넌트 간격 | 기존 간격 (v00191) | **개편 후 간격 (v00192)** | 최적화 효과 |
| :--- | :---: | :---: | :--- |
| **보관 통계 위젯 ↔ 퀵 서치 바** | `20px` | **`14px`** (-6px) | 위젯과 검색창의 시각적 결합도 향상 |
| **퀵 서치 바 ↔ 유통기한 도래 물건** | `28px` | **`20px`** (-8px) | 넉넉했던 여백을 줄여 핵심 리스트 접근성 강화 |
| **유통기한 도래 ↔ 최근 활동 물건** | `32px` | **`22px`** (-10px) | 섹션 간 과도한 단절감 해소 및 연속성 확보 |
| **각 섹션 제목 ↔ 카드 리스트** | `16px` | **`12px`** (-4px) | 제목과 목록 아이템 간의 응집도 향상 |

```text
┌──────────────────────────────────────────────┐
│ [🏠 내 보관소] (토스 플로팅 뱃지 바)          │
│                                              │
│ [보관 통계 위젯] (총 물건 / 보관 공간 / 수납처) │
│   ↕ 14px (기존 20px)                         │
│ [퀵 서치 바: 어떤 물건을 찾고 계신가요?]        │
│   ↕ 20px (기존 28px)                         │
│ [유통기한 도래 물건] (🚨 ⚠️ ⏰ 리스트)        │
│   ↕ 22px (기존 32px)                         │
│ [최근 활동 물건] (신규 / 수정 리스트)         │
└──────────────────────────────────────────────┘
```

### 1.2. 기대 효과
- **Above-the-fold(첫 화면) 공간 30px 이상 확보**: 모바일 기기 화면에서 첫 화면에 노출되는 정보 밀도가 최적화되어 스크롤 피로도가 크게 감소했습니다.
- **토스 미니멀 디자인 완성도**: 각 컴포넌트가 적절한 여백과 응집도를 유지하며 더욱 정돈되고 완성도 높은 대시보드 룩앤필을 제공합니다.

## 2. 변경 파일 요약

1. `src/components/HomeTab.tsx`:
   - 통계 위젯, 퀵 서치 바, 유통기한 도래 섹션, 최근 활동 섹션의 상하 마진(`marginBottom`) 최적화 적용
2. `src/version.ts`:
   - `APP_VERSION = 'v00192'`
3. `.env`:
   - `VITE_APP_VERSION=v00192`
4. `docs/walkthrough_v00192.md`:
   - 신규 워크스루 문서 작성 및 구글 드라이브 동기화
