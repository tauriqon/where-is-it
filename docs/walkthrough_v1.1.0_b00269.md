## 1. 개선 배경 및 목적
- **초대 코드 박스 간결화**: '일회용 가족 초대 코드' 아래 붉은색 원으로 표시되었던 부가 문구(`24시간 유효 · 가족 승인 시 즉시 소멸`)를 삭제하여 코드 박스를 슬림하고 깔끔하게 정돈.
- **입력창 및 버튼 크기/폰트 통일**: '새로운 공유 보관소 참여 신청하기' 섹션의 입력창과 신청 버튼이 다른 화면의 표준 규격보다 작게 축소되어 있던 점을 표준 규격(높이 `52px`, 폰트 `16px`)으로 통일.
- **상하 위치 및 여백 최적화**: 화면 진입 시 상단 헤더와의 불필요한 공백을 줄이고, 하단 네비게이션 바에 의해 신청 버튼 및 안내 문구가 가려지지 않도록 상하 위치와 여백을 균형 있게 재조정.

---

## 2. 세부 변경 사항

### 1) 일회용 가족 초대 코드 부가 문구 삭제
- **파일**: `src/components/SettingsTab.tsx`
- **변경 전**: 초대 코드 하단에 `24시간 유효 · 가족 승인 시 즉시 소멸` 표시
- **변경 후**: 해당 텍스트를 삭제하고, 박스 패딩을 `12px 14px`로 정돈하여 초대 코드와 조작 버튼([새 코드], [복사], [공유])이 한 줄에 깔끔하고 직관적으로 표시되도록 개선.

### 2) 새로운 공유 보관소 참여 신청하기 입력창 & 버튼 통일
- **파일**: `src/components/SettingsTab.tsx`
- **입력창 (`<input>`)**:
  - 기존: `minHeight: 46px`, `fontSize: 14px`
  - 변경: `minHeight: 52px`, `height: 52px`, `fontSize: 16px`, `fontWeight: 600`, `borderRadius: 14px` (표준 입력창과 완벽 통일)
- **신청 버튼 (`<button className="btn-primary">`)**:
  - 기존: `minHeight: 46px`, 기본 폰트
  - 변경: `minHeight: 52px`, `height: 52px`, `fontSize: 16px`, `fontWeight: 600`, `borderRadius: 14px` (표준 메인 액션 버튼과 완벽 통일)

### 3) 가족 동기화 화면 전체 상하 위치 및 여백 조정
- **상단부 조정**:
  - 상단 고정 헤더 직하단의 중복 설명 문단(`<p className="body-desc">`)을 제거하고 상단 여백을 정돈하여, 화면 시작 지점이 헤더 아래에 자연스럽고 컴팩트하게 밀착되도록 조정.
- **섹션 간격 및 카드 패딩**:
  - 메인 카드 패딩을 `20px` ➔ `16px 18px`, 내부 섹션 간격을 `24px` ➔ `16~18px`로 최적화하여 스마트폰 화면 안에서 전체 컨텐츠가 안정적인 비율로 시야에 들어오도록 개선.
- **하단 여백 확보**:
  - 전체 컨테이너 하단에 `paddingBottom: 36px`을 추가하여, 스크롤을 내렸을 때 신청 버튼이 하단 탭 바에 가려지지 않고 손쉽게 터치할 수 있는 여유 공간 확보.
