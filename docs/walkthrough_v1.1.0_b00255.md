## 2. 토스 플랫폼 아키텍처 및 근본 원인 규명

### 2.1. 상단 `[··· ✕]` 캡슐 버튼의 기술적 실체
- 토스 미니앱 상단 우측에 항상 노출되는 `··· ✕` 캡슐 버튼은 웹뷰가 렌더링하는 영역이 아닌, **토스 네이티브 OS(안드로이드 Java/Kotlin) 레벨의 시스템 오버레이 컨트롤러**입니다.
- **토스 공식 SDK 규격**:
  > *"앱인토스(토스 미니앱) 개발 환경에서 상단 내비게이션 바의 닫기('X') 버튼 클릭을 직접 감지하여 콜백을 실행하는 기능은 공식적으로 제공되지 않습니다. 미니앱의 상단 닫기 버튼은 토스 앱 내의 네이티브 영역에 속해 있어, 웹뷰 내부에서 직접적인 클릭 이벤트를 바인딩하거나 가로챌 수 없도록 설계되어 있습니다."*
- 악의적인 웹뷰가 사용자를 강제로 가두는 것을 방지하기 위한 플랫폼 비상 탈출구이므로, 웹뷰의 JavaScript(`homeEvent`, `beforeunload`, `click` 등)로는 **네이티브 `[✕]` 클릭을 가로채거나 모달을 띄우는 것이 플랫폼 차원에서 원천 차단**되어 있습니다.

### 2.2. 왜 토스 전체가 닫히고 스마트폰 홈 런처로 나가는가? (안드로이드 딥링크 특성)
- 현재 개발 및 테스트는 **토스 개발자 센터의 QR 코드 스캔 또는 `intoss-private://` 테스트 딥링크**를 통해 수행됩니다.
- 안드로이드 OS는 외부 딥링크/스킴으로 진입할 때 미니앱을 **단독 태스크(Single Task / `FLAG_ACTIVITY_NEW_TASK`)**로 생성합니다.
- 따라서 뒤에 토스 메인 화면이 깔려있지 않으며, 상단 `[✕]`를 누르면 태스크의 유일한 화면(`MiniAppActivity`)이 종료되면서 스마트폰 바탕화면으로 나가게 됩니다.
- 안드로이드 OS의 태스크 관리자는 해당 딥링크 태스크의 캡처본을 최근 앱 목록에 남겨두므로, 멀티태스킹 창에서 WhereIsIt이 여전히 올라와 있는 것처럼 보이게 됩니다.
- **정식 출시(운영 환경)와의 차이**: 정식 출시 후 사용자가 토스 앱 내부(전체 탭, 혜택, 검색 등)에서 WhereIsIt에 진입한 경우에는, `[✕]` 터치 시 원래 보고 있던 토스 메인 화면으로 100% 정상 복귀합니다.

## 3. 조치 및 개선 사항 (`v1.1.0-b00255`)

1. **설정 탭(`SettingsTab`) 내 명시적 [🚪 앱 종료하기] 버튼 신설**
   - 네이티브 `[X]`와 무관하게 사용자가 앱 내부에서 명확하게 종료할 수 있도록, 설정 탭 최하단에 토스 스타일의 **`[🚪 앱 종료하기]`** 버튼을 추가했습니다.
   - 버튼 터치 시 즉시 **"아 찾았다!를 종료할까요?"** 확인 모달이 뜨며, `[닫기]` 시 머무르고 `[종료하기]` 시 `openURL('supertoss://home')` 및 `Screen.close()`를 통해 토스 홈으로 안전하게 복귀합니다.

2. **안드로이드 표준 시스템 뒤로가기 제스처 연동 안내**
   - 홈 화면 상태에서 스마트폰의 **시스템 뒤로가기 버튼(또는 가장자리 쓸어넘기기 제스처)**을 실행하면 앱의 `backEvent`가 정상 작동하여 언제든지 종료 확인 모달을 띄울 수 있습니다.
