# 📦 WhereIsIt 물건 상세 정보 바텀시트 헤더 물건명 직관화 및 중복 정리 (v00190)

본 문서는 WhereIsIt 미니앱에서 물건 상세 정보 바텀시트 열람 시, 상단에 노출되던 일반적이고 당연한 안내 문구(`[물건 상세 정보]`) 대신 **실제 물건 이름(`currentItem.name`)과 개인 물건 뱃지(`🔒 개인`)를 최상단 헤더에 즉시 노출**하고, 사진 아래 중복되던 대제목을 정리하여 모바일 가독성과 공간 활용성을 극대화한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

---

## 1. [v00190] 주요 변경 및 개선 사항

### 1.1. 최상단 고정 헤더에 실제 물건 이름 및 개인 뱃지 배치
- **기존 문제점**: 바텀시트가 열렸을 때 상단에 `[물건 상세 정보]`라는 일반적인 제목만 보이고, 사용자가 누른 물건이 무엇인지 확인하려면 사진 아래로 시선을 내려야 했습니다.
- **개선 내용**:
  - 바텀시트 상단 고정 헤더(`bottom-sheet-header`)의 제목에 **실제 물건 이름(예: `비상약 상자`, `타이레놀 500mg`)**과 **`🔒 개인`** 뱃지를 바로 배치했습니다.
  - 아래로 스크롤을 내려 보관 위치 사진이나 유통기한, 태그 등을 확인할 때도 **어떤 물건을 보고 있는지 헤더에 항상 고정(Sticky)**되어 인지성이 대폭 향상되었습니다.

```text
┌──────────────────────────────────────────────┐
│ [  ㅡ  ] (드래그 핸들)                         │
│ 타이레놀 500mg 🔒개인                     [ X ]│  <-- 물건 이름이 최상단에 즉시 고정!
├──────────────────────────────────────────────┤
│ [                물건 사진                    ] │
│                                              │
│ 작성된 설명 / 메모                             │  <-- 중복 제목 제거 후 설명/위치 직결
│ [보관 위치: 거실 > 수납장 > 1번 서랍]           │
│ 수량: 1개  /  유통기한: 2026-10-15 [⚠️ 오늘까지] │
└──────────────────────────────────────────────┘
```

---

### 1.2. 사진 하단 중복 제목 정리 및 시원한 화면 구성
- 상단 헤더에 이미 물건 이름이 명확히 표시되므로, 사진 밑에서 크고 굵게 중복 노출되던 `h2` 물건 이름을 제거했습니다.
- 사진 바로 밑으로 **작성된 설명/메모(`currentItem.description`)** 및 **보관 위치 카드**가 자연스럽게 이어져 불필요한 스크롤과 시각적 낭비를 줄였습니다.

---

### 1.3. 수정 모드(`isEditing`)와의 매끄러운 상태 전환
- 상세 열람 상태: `[물건 이름] 🔒 개인` 노출
- `[수정]` 버튼 탭 시: 기존과 동일하게 `[물건 정보 수정]` 타이틀로 전환되어 현재 입력/편집 상태임을 명확하게 인지할 수 있도록 유지했습니다.

---

### 1.4. 공통 `BottomSheet` 컴포넌트 강화 (`src/components/BottomSheet.tsx`)
- `title` prop 타입을 `string | React.ReactNode`로 확장했습니다.
- 제목 영역에 `flex: 1`, `minWidth: 0`, `gap: 12px`을 적용하여 긴 물건 이름이나 뱃지가 포함되어도 우측 닫기 버튼(`[X]`)이 찌그러지거나 겹치지 않도록 안전한 레이아웃을 구축했습니다.
