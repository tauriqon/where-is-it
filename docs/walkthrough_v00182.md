# 📦 WhereIsIt 물건 등록 화면 [저장]·[취소] 버튼 그룹 및 모바일 하단 여백 최적화 (v00182)

본 문서는 WhereIsIt 토스 인앱 미니앱의 물건 등록(AddTab) 화면에서 **하단 제출 버튼을 [저장]으로 간결화**하고, 사용자가 입력을 안전하게 중단하고 복귀할 수 있도록 **[취소] 버튼을 추가**하며, 일부 기종(노치형 아이폰, 제스처 내비게이션 바가 있는 안드로이드 등)에서 하단 탭 바에 의해 마지막 버튼이 가려지거나 잘리는 현상을 **세이프 에어리어(Safe Area) 및 상하 간격 최적화**를 통해 완벽히 해결한 작업 내역을 정리한 워크스루(Walkthrough)입니다.

## 1. [v00182] 주요 변경 및 개선 사항

### 1.1. 배경 및 문제점 해소
- **버튼 명칭 직관화 및 [취소] 기능 부재 해소**:
  - 기존의 기다란 `[물건 기록 완료]` 텍스트를 앱 전반의 표준 액션 레이블인 **`[저장]`**으로 간결화하였습니다.
  - 실수로 등록 화면에 진입했거나 입력을 취소하고 싶을 때 즉시 안전하게 홈으로 돌아갈 수 있는 **`[취소]`** 버튼을 좌측에 나란히 배치하였습니다.
  - 작성 중인 내용이 있을 때 취소를 누르면 확인 창(Confirm)을 띄워 작성 중 데이터가 실수로 유실되지 않도록 방어 로직을 적용했습니다.
- **일부 폰에서 하단 버튼이 잘리거나 가려지는 현상 원천 해결**:
  - 기존 `.scrollable` 컨테이너의 하단 패딩이 `padding-bottom: 90px;`로 고정되어 있었습니다.
  - 최신 스마트폰(아이폰 13~16, 제스처 바 안드로이드)의 하단 내비게이션 탭 바 높이는 기본 높이(68px)에 기기별 세이프 에어리어(아이폰의 경우 34px)가 더해져 **총 102px 이상**에 달합니다.
  - 이로 인해 최하단으로 스크롤하더라도 버튼의 하단부(12px 이상)가 탭 바 뒤로 가려지는 문제가 있었습니다.
  - `.scrollable`에 동적 세이프 에어리어 계산식 `padding-bottom: calc(88px + max(24px, env(safe-area-inset-bottom)));`을 적용하고, 등록 화면 폼 최하단에도 여유 여백을 부여하여 **어떤 스마트폰 기종에서도 버튼이 시원하게 노출**되도록 해결했습니다.
- **폼 필드 간 상하 간격(Vertical Rhythm)의 쾌적한 균일화**:
  - 각 폼 필드 그룹 간 중복 마진을 정돈하고 일관된 `gap: 24px`을 적용하여 시각적 답답함과 불규칙성을 해소했습니다.
